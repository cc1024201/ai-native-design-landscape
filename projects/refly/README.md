# Refly

> Research status: **Source-level** · Lifecycle: **active** · Last reviewed: **2026-08-12**

Refly is an agentic workspace that turns an editable canvas and reusable workflow into a stable, versioned agent skill that can run in Refly or leave the product through other delivery surfaces.

## SOPs compile into skill infrastructure

Resources and steps arranged on the canvas become a workflow plan and then a skill package. Skill services map workflow structure into executable plans, while the package layer handles installation, versions, publication, and invocation. A skill is therefore more durable than the chat that initiated it.

## Intervention is a runtime feature

Workflow processors stream progress and preserve step outputs. Users can inspect, interrupt, or rerun parts of the process, and canvas synchronization keeps collaborators aligned around the same project state rather than a collection of private transcripts.

## Delivery has several explicit forms

A versioned skill can be forked or published, exported for Claude Code, exposed through API or MCP, or wrapped in a workflow application. Code and media artifacts remain separate resource types attached to the canvas and execution history.
