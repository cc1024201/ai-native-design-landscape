## Scope

A multi-agent application-building environment that uses specialized agents to plan, design and implement software from high-level requirements.

## Technical direction

- Uses role-specialized agents for different stages of software creation.
- Presents generated application output through a browser-oriented builder workflow.
- Treats design as one step inside a broader autonomous software-development pipeline.
- Targets end-to-end generated applications rather than standalone design documents.

## Public technical choices

- Surface: web application builder.
- Agent model: multi-agent orchestration.
- Artifact: generated application/code.
- Workflow: requirements → agent work → runnable result → iteration.
