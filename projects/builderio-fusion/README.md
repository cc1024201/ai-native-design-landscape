## Scope

An AI product/design/code environment centered on a visual canvas that can operate against an existing codebase.

## Technical direction

- Treats the visual canvas as an editing surface over production-oriented code.
- Uses existing components and design-system context rather than rebuilding a parallel UI library.
- Combines direct visual changes with agent-driven code actions.
- Targets a repo/PR-oriented shipping workflow.

## Public technical choices

- Surface: visual canvas plus AI agent.
- Code relationship: existing repository/component context.
- Editing: layout, spacing, styling and content through visual interaction.
- Output: implementation changes suitable for repository workflows.
