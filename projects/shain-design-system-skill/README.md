# Shain Design System Skill

> Research status: **Architecture-level** · Lifecycle: **active** · Last reviewed: **2026-08-12**

Shain Design System Skill is a separately released companion to Shain Designer Kit for creating and evolving token-based Figma systems. It defines primitive, semantic and component-specific token tiers, light and dark modes, component properties, naming, accessibility and design-to-code handoff.

## The native Figma system is the intended authority

The skill describes how variables, auto layout, variants and component structure should be created in Figma, then mapped to BEM-style CSS and theme configuration. Reference documents guide migration and deprecation as the token system changes; the skill itself does not host or persist the graph.

Because its repository contains the operating contract and references but no independent Figma mutation runtime, the evidence ceiling is architecture level. Separate releases and direct installation make it a companion product rather than an internal file of the Designer Kit.
