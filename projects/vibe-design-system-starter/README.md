# Vibe Design System Starter

> Research status: **Source-level** · Lifecycle: **active** · Last reviewed: **2026-08-12**

Vibe Design System Starter makes visible UI work pass through a repository-local design operating system before an agent writes code. It is not a component library and does not replace Figma or Tailwind; it supplies the durable decision contract between a feature request and those tools.

## Local rules become the source of design constraint

Installation adds product context, taxonomy, presets, tokens, component anatomy, screen patterns, prompt contracts and review checks. `AGENTS.md` routes any visible feature request through this material even when the user never says “design.” The agent classifies the job, selects a product posture and reports which constraints it applied.

The repository contract is authoritative for design-system choices; application code materializes them. Figma, shadcn and other registries can be evidence or implementation inputs but cannot silently override local tokens and states. Verification scripts make drift auditable without claiming deterministic checks can judge overall product quality.
