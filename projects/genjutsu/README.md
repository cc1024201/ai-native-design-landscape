# genjutsu

> Research status: **Source-level** · Lifecycle: **active** · Last reviewed: **2026-08-12**

genjutsu is a cross-stack creative-coding system for agents. Its two orchestration skills separate focused motion work from a full visual-system build and force creative direction to become visible before implementation.

## Approval artifacts carry qualities that prose cannot

[`cast`](https://github.com/AThevon/genjutsu/blob/08a792f6403104a231fc3f9b1612577698d6e03d/skills/cast/SKILL.md) runs a seven-stage interaction pipeline; [`paint`](https://github.com/AThevon/genjutsu/blob/08a792f6403104a231fc3f9b1612577698d6e03d/skills/paint/SKILL.md) builds a visual universe and persistent stack-aware `MASTER.md`. Both pause at thesis, variant and identity gates.

At a gate the user can request a live artifact with real motion and contrast data, a temporary preview route in the target stack, or an inline description. Approved preview files are intentionally disposable; the repository's actual source and generated design-system files become authoritative. The bundled `ui-ux-pro-max` data remains an acknowledged upstream module rather than a second genjutsu product.

The maintainer's first-party profile identifies Toulouse, France.
