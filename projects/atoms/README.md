## Scope

A multi-agent natural-language software-building product for generating and refining websites, applications, dashboards and other working software artifacts.

## Technical direction

- Uses multiple specialized agents to decompose product, architecture, engineering, research and data tasks.
- Provides live rendering while agents generate and update the application.
- Supports visual editing by selecting rendered elements and describing precise changes.
- Combines generated frontend, backend/integration work and deployment inside the same builder workflow.

## Public technical choices

- Agent model: multiple specialized software-development agents with distinct roles.
- Surface: live-rendered application preview with element-level visual editing.
- Integrations: public materials describe GitHub, Supabase, Stripe and other connected services.
- Product continuity: official help material states that MGX has been rebranded to Atoms and that MGX originated as MetaGPTX built on MetaGPT.
