## Scope

An open-source agentic IDE built around the browser/runtime, application previews and coding-agent orchestration.

## Technical direction

- Makes the browser a first-class development and agent-observation environment.
- Allows rendered application context to be selected and supplied to the agent.
- Combines code, browser/runtime and git workflows in one environment.
- Owns both the agent experience and the visual/runtime surface.

## Public technical choices

- Surface: browser-centric agentic IDE.
- Artifact: local software project and running application.
- Targeting: DOM/application context from preview.
- Implementation: open-source codebase.
