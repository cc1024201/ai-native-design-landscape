## Scope

A desktop frontend workspace putting browser, code editor, terminal, DevTools and AI targeting into one interface.

## Technical direction

- Maps selected rendered elements to exact source context.
- Uses point/area/multi-selection as a high-bandwidth input channel for coding agents.
- Keeps the running app, source editor and agent interaction adjacent.
- Supports reference-image and responsive UI workflows.

## Public technical choices

- Surface: browser + editor + terminal + DevTools.
- Targeting: element selection with source file and line information.
- Visual context: area selection and multiple queued edits.
- Artifact: existing frontend codebase.
