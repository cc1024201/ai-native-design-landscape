## The canvas is a coordination surface between design and agents

Uitiful generates structured interface concepts and retains them in a visual workspace for continuing refinement. A local coding agent can connect to that workspace so visual decisions and implementation can advance with shared context instead of passing screenshots between tools.

The product describes a continuous loop—prompt inspect refine connect ship—rather than a one-time generation. Semantic HTML provides an implementation-shaped representation; the canvas carries visual state and iteration context; delivery creates a Web native-app or Figma-facing materialization.

## Current fact versus announced direction

The first-party page mixes available early-access capabilities with planned paths. Core generation iteration private canvas and local-agent workflow are offered in current plans. Native iOS and Android are repeatedly described as “plan” or early-access delivery and Figma appears both as export language and roadmap access. This dossier does not upgrade those statements into general availability.

The implementation data model transport protocol and lossless round-trip semantics are not public. Accordingly this record is architecture-level and active-transition.
