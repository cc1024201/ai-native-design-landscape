# Super Design Skills

> Research status: **Architecture-level** · Lifecycle: **active** · Last reviewed: **2026-08-12**

Super Design Skills is a product-design methodology layer for Claude Code. It does not claim a proprietary canvas; it imposes option-driven discipline around whatever design and prototyping tools the host already exposes.

## One rigid rule changes the decision topology

The central rule requires three or more genuinely distinct directions before convergence. Skills then cover framing, writing a spec, critique, visual QA, stakeholder narrative, handoff and pre-shipping verification. A session hook injects a meta-skill that routes relevant work into this sequence.

Outputs are durable files—a framed direction, option set, spec, QA report, presentation script and engineering handoff. Figma or code prototypes can supply the visual artifact, but the product's own authority is the decision trail and required gates. The repository labels several skills as light scaffolds, so this dossier treats the released method as current while avoiding a claim that every route has equal implementation depth.
