# Mobirise AI

> Research status: **Architecture-level** · Lifecycle: **active** · Last reviewed: **2026-08-12**

Mobirise AI is the AI-mediated path inside the established Mobirise site builder. Its ordinary-user loop starts from a text or image brief and stays inside one editable site through manual or conversational refinement publishing and optional HTML/CSS/JavaScript export.

## The site project is the durable boundary

The official product contract describes generation of an initial structure and design followed by changes to layout palette typography imagery content SEO commerce and forms. Mobirise release notes separately expose project-level operations such as new-page generation block cloning global CSS saving and a recent-generations list. Those facts support a managed site graph rather than a sequence of disconnected images.

## AI and direct editing converge before delivery

The user can request precise changes in chat or use the builder's normal block and style controls. Publication can target Mobirise hosting and a connected domain. Full source export establishes a second delivery path without proving that exported source is the internal authoring authority; the native Mobirise project therefore remains the best-supported primary authority.

## Evidence boundary

The public GitHub repository is a release-history and template surface rather than the current application source. This dossier can establish the product loop and authority boundary but not the private mutation protocol or persistence schema. Claims about internal models and storage are deliberately left open.
