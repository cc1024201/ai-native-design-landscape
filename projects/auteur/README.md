# auteur

> Research status: **Source-level** · Lifecycle: **active** · Last reviewed: **2026-08-12**

auteur treats a website as a directed sequence of scenes. The skill profiles reference sites, captures a licensed moodboard and shot plan, generates or sources assets, builds the implementation and gates it against responsive screenshots and cross-route system drift.

## The commit sheet connects direction to delivery

Design references and shots become repository artifacts before code generation. Browser capture and an executable anti-slop linter then compare the built source with those decisions. Generated assets, their licenses and route-level design-system checks stay inspectable instead of being hidden in a one-shot page prompt.

The workflow can call optional image and Blender tools, but the site source and retained design artifacts are authoritative. The repository explicitly does not publish a numerical quality benchmark.
