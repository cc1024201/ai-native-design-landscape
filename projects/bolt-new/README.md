## Scope

A browser-based AI software builder that increasingly incorporates design-system context and frontend visual consistency into agent generation.

## Technical direction

- Builds executable applications from natural-language instructions.
- Uses existing design-system/component context to constrain generated UI.
- Connects design references to implementation components.
- Keeps generation inside a browser development runtime.

## Public technical choices

- Surface: browser-based coding/preview environment.
- Artifact: full application code.
- Design-system path: ingest/reuse component and style context.
- Runtime: web-native development environment.
