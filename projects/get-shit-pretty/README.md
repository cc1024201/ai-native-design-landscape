# Get Shit Pretty

> Research status: **Source-level** · Lifecycle: **active** · Last reviewed: **2026-08-12**

Get Shit Pretty (GSP) is a repository-native brand and product-design system for coding agents. It encodes two connected design diamonds—brand formation and product creation—then checks the built interface against the resulting design intent.

## `.design/` is a durable chain from research to verdict

Each brand and project has a brief, configuration and `STATE.md`; automatic session recovery reloads the active phase. The [architecture contract](https://github.com/jubscodes/get-shit-pretty/blob/5754ce8c44cd9cc9d9207e25955a1a89cf875bb8/ARCHITECTURE.md) separates pipeline skills that own gates and state from expertise skills that own color, type, imagery, icons and critique knowledge.

Brand phases produce research, strategy, identity and W3C-style tokens. Product phases produce screen/flow specifications and `preview.html`, run heuristic and accessibility critique, build components/screens in bounded waves, and issue a Pass/Conditional/Fail implementation verdict. Source code and `.design/` artifacts jointly preserve authority; Figma MCP is an input bridge.

The maintainer's first-party profile identifies Florianópolis, Brazil.
