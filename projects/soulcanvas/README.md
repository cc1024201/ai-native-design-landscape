# 灵境画布

> Research status: **Architecture-level** · Last reviewed: **2026-08-12**

灵境画布 treats the creative process itself as retained project data. References plans costs intermediate results and lineage remain beside the final media.

## Observable agent execution

A user creates or resumes a project places product images visual references notes or video on an infinite canvas and chooses free creation or Agent mode. In Agent mode the system shows its analysis plan tool calls progress and expected credit cost. Each step can be inspected paused retried or continued.

Generated results return to the canvas automatically. They can be arranged grouped compared and selected for another operation such as retouching generating a sibling image or turning an image into video. This makes one result an input node in a continuing lineage instead of a disposable download.

```mermaid
flowchart LR
    R["References and goal"] --> P["Visible agent plan"]
    P --> X["Pausable tool execution"]
    X --> O["Results on infinite canvas"]
    O --> V["Compare group and select"]
    V --> X
    O --> D["Image or video delivery"]
```

## Persistence contract

The first-party product explicitly says prompts reference material agent plans generated results and version relations are retained when the project is reopened. That is the strongest differentiator here. Public evidence does not disclose how nodes are serialized whether history is branched internally or which model providers execute each operation.

The operating team and region are not established by the public page. A `.cn` domain and Chinese-language surface are discovery context not geography evidence.
