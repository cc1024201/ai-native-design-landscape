# DaVinci Resolve

> Research status: **Architecture-level** · Lifecycle: **active** · Last reviewed: **2026-08-12**

DaVinci Resolve 21 is an established native media platform whose current AI tools operate inside the same editing, color, Fusion, Fairlight, photo and delivery project. The AI layer is therefore not a parallel generator: it changes or helps navigate the timeline, tracked subject, node graph and shared project a professional already controls.

## AI results stay adjustable in native workspaces

The [current release](https://www.blackmagicdesign.com/products/davinciresolve/whatsnew) includes content and face search, slate metadata extraction, generated speech, focal-plane reconstruction, facial age and feature adjustment, blemish removal, sharpening and motion deblur. CineFocus is a representative authority boundary: a user chooses the focal subject, adjusts aperture and range and can keyframe a rack focus. Face tools similarly expose manual parameters after detection instead of returning only rendered media.

The [product architecture](https://www.blackmagicdesign.com/products/davinciresolve) keeps cut/edit timelines, Fusion graphs, color nodes and group versions, Fairlight audio and delivery inside one project, with Blackmagic Cloud supporting concurrent collaborators. AI inference proposes selections or transformations; native controls, versions and the saved Resolve project remain authoritative. The separately counted Unofficial DaVinci MCP can drive or materialize into this host, but it does not own Blackmagic's project graph.
