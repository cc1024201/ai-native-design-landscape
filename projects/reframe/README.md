## Scope

An experimental design engine exploring structured, inspectable design representations that can be manipulated by both humans and agents.

## Technical direction

- Explores HTML/structured-node representations instead of opaque design-only graphs.
- Treats design state as editable and inspectable data.
- Targets multiple render/export surfaces from a shared structured artifact.
- Emphasizes auditability and agent manipulation.

## Public technical choices

- Representation: HTML plus structured node/AST concepts.
- Surface: visual design/editor experiments.
- Agent orientation: structured state intended for programmatic manipulation.
- Implementation: public repository.
