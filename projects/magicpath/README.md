## Scope

A shared infinite design canvas where humans and external agents can create, inspect and refine interactive UI artifacts.

## Technical direction

- Makes the canvas a shared workspace for human and agent actions.
- Allows external agents to drive design work through integrations/MCP.
- Supports repo-to-canvas and canvas-to-repo workflows.
- Keeps generated UI interactive rather than treating it as a flat mockup.

## Public technical choices

- Surface: multiplayer infinite canvas.
- Artifact: interactive UI/design with generated React code.
- Agent interface: external-agent/MCP workflows.
- Context: repository, design references and canvas selection.
