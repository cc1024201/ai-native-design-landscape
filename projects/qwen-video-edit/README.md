# Qwen MM Plugins — Video Edit

> Research status: **Source-level** · Lifecycle: **active** · Last reviewed: **2026-08-12**

Qwen's video-edit capability is a separately installable media-production skill and MCP package. It coordinates image, video and audio generation/editing tools with reusable motion atoms, transition code, fonts and previewable style packs.

## A skill-owned production kit shapes generated media

The component carries its own plugin manifests and runtime package. Its asset tree provides named atom packs and browser previews so an agent can compose a directed visual system rather than issue an isolated generation prompt. Produced media files are delivery artifacts; the skill assets and edit instructions are the recoverable process boundary.

Several generation backends are external services, so repository evidence establishes orchestration and packaged art direction but not provider persistence or deterministic regeneration.
