# Emdash Skills

Emdash Skills treats design as a stage that must survive delivery — brand and interface are only "done" once they pass hard gates, not when a generation looks right. Its answer to "what is design" is a set of source modules (tokens, interaction rules, application slices, infrastructure) that a router threads through brief, research, architecture, build, design system, motion and media before quality and deploy.

The decisive mechanism is the gate graph. Parallel build and verify agents operate the consuming repository, and the design must clear Playwright screenshots at six breakpoints, vision review, Lighthouse, axe, SEO and console checks as release evidence. Only after those gates does the workflow deploy to Cloudflare and independently verify the live result. The repository and the deployed runtime are two explicit authorities: source owns the design definition, and the browser-owned gates own acceptance.

Because the design system, motion and media modules are internal stages of one router rather than separate teams, the suite reads as one coherent end-to-end product — the design is not its own artifact but one slice of a pipeline whose persistence is the verified, deployed site.
