# Figma MCP Server

Figma MCP Server answers "what is design" by deferring to the design that already lives in Figma. It is Figma's official interface that lets external agents reach into native Design, FigJam and Slides artifacts, and like the TalkToFigma-style control plane it refuses to define design itself: authority always stays with the Figma file and its native nodes. But where the standalone bridges are read-only or thin, this is Figma's own **bidirectional** contract — external agents both read design/code context and write changes back to native artifacts under explicit account and plan authority, running bounding Figma Plugin API code against frames, components, variables, auto-layout and canvas ([official guide](https://github.com/figma/mcp-server-guide/tree/22b2c566d98880ebdb5a8e48eb2c66c596a6d990)).

The decisive mechanism is the **skill-packaged plugin surface over the hosted REST/plugin backend**. Reading skills pull the selected design context or convert design to code; writing skills create new files, deliver native Design generation, draw FigJam diagrams, build Slides and generate libraries. `create_new_file` resolves the user's plan before creating a draft, and Code Connect provides the one piece of cross-boundary identity: component identity across the design/code line. The persistence and authority model is what the external agent is told to trust — a returned URL or file key addresses subsequent work, and write operations occur under Figma permissions ([create-new-file contract](https://github.com/figma/mcp-server-guide/blob/22b2c566d98880ebdb5a8e48eb2c66c596a6d990/skills/figma-create-new-file/SKILL.md), [native execution contract](https://github.com/figma/mcp-server-guide/blob/22b2c566d98880ebdb5a8e48eb2c66c596a6d990/skills/figma-use/SKILL.md)).

It is deliberately separate from the built-in Figma Design Agent: this server is what an external client uses, distinct from the product's own in-app agent. The hosted implementation itself is closed — internal routing, transaction isolation and persistence mechanics are unknown — so the analysis rests on the public skill contract, which is the whole surface an external agent can rely on. Design lives in the file; this server is how an agent reaches it.
