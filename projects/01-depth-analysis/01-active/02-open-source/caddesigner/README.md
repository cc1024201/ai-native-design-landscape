# CADDesigner

CADDesigner's answer to "what is design" is uncompromising: design is **executable CAD source**, not a mesh and not a rendered thumbnail. It refuses to let a model emit an opaque solid and call that CAD. Instead its specialist agent writes precise CAD code into a per-task workspace, runs that code through a domain CAD kernel, checks the required outputs and — on failure or visual inspection — revises the same source ([agent orchestration](https://github.com/562590763/CADDesigner-Code/tree/65b5f5219974eadbd3ea1d117e467f47cefb69b7)). The rendered solid is only a projection; the source file carries reproducible construction intent, and the kernel decides whether that intent yields valid geometry.

That principle sets the implementation's shape. The generator is given a concrete file contract: `CADAgent.py` runs code tools that create or update exact workspace files rather than returning unattached snippets, and completion demands real artifacts — STL plus STEP/STP exchange forms ([pinned source](https://github.com/562590763/CADDesigner-Code/blob/65b5f5219974eadbd3ea1d117e467f47cefb69b7/agent/CADAgent.py)). Delivery is deliberately double-checked because a `.stl` tessellation alone can lose parametric construction and precise exchange semantics, while a STEP alone is insufficient if the source cannot be regenerated or changed.

The mechanism closes two different feedback loops against that source. **SketchPad** is semantic working memory — structured requirements, reference images and visual facts keyed by IDs that keep later turns grounded in intent, but explicitly not the geometry itself ([sketch_pad.py](https://github.com/562590763/CADDesigner-Code/blob/65b5f5219974eadbd3ea1d117e467f47cefb69b7/context/sketch_pad.py)). Execution errors expose syntax and kernel failures; model-view tools render outputs for visual inspection — and neither alone proves correctness, so a proper run inspects code validity, geometry production, rendered shape and recorded requirements together. Persistence separates conversation state (Redis plus JSON recovery) from the workspace file tree, which supports restart recovery but is not a CAD-native version graph — no immutable revisions, no three-way merge. Design, here, is the artifact an engineer can re-run and re-edit, and it lives in the source, not the picture.
