# Figma Console MCP

Figma Console MCP answers "what is design" by locating it entirely inside the host: the design is the native Figma, FigJam and Slides file a team already owns, and this project's job is to let an AI client reach it. It does not generate, translate or store a second artifact; its own screenshot, audit and export files are projections that never replace the targeted graph as the authority for layout and node identity ([pinned tool reference](https://github.com/southleft/figma-console-mcp/blob/08ff31edbf1c4a57a2564d5020d4e28453eea10f/docs/tools.md)).

The decisive mechanism is that capability is a function of transport, not of the repository. The pinned contract derives three paths: remote SSE is a small read-only exploration surface; cloud mode pairs a web AI client with the Figma Desktop bridge to enable writes; local NPX/source mode combines REST with the local Desktop Bridge plugin and exposes the full tool set including live monitoring (revision [`08ff31ed`](https://github.com/southleft/figma-console-mcp/tree/08ff31edbf1c4a57a2564d5020d4e28453eaa10f)). A successful read from one session therefore never implies write authority in another — the write surface only exists where the plugin closes the gap that Figma's REST API leaves open.

The Desktop Bridge runs inside Figma and exchanges requests with the MCP server over a local WebSocket, creating or mutating frames, nodes, components, variables, FigJam objects and Slides content. That is the decisive mutation surface in [`src/core/write-tools.ts`](https://github.com/southleft/figma-console-mcp/blob/08ff31edbf1c4a57a2564d5020d4e28453eaa10f/src/core/write-tools.ts). The project is also broader than a context extractor: tokens travel both directions via DTCG and code formats, with schema/parsers and gated operations for creation, rename, alias retargeting and deletion rather than a blind overwrite ([`src/core/tokens/`](https://github.com/southleft/figma-console-mcp/blob/08ff31edbf1c4a57a2564d5020d4e28453eaa10f/src/core/tokens/)) — useful but risky when code and design variables have both changed.

Multi-file execution is explicit and guarded: `figma_execute_across_files` requires a named list or `allFiles: true` and does not silently fan out, because a bulk audit and a bulk mutation have very different consequences, and the source establishes no cross-file transaction that rolls everything back on partial failure. Version tools analyze host versions without owning them; local caches accelerate comparison but recovery still depends on Figma's own permissions and history. The design act is thus deliberate mutation of a foreign document graph with authority tightly coupled to the transport chosen.
