# genjutsu

genjutsu treats design as creative direction that must become legible before any code is written. It is a cross-stack creative-coding system for agents, and its whole architecture is organized around forcing the "why" of a visual — the thesis, the variant, the identity — to be approved as an artifact, not assumed inside an opaque generation. The two orchestration skills split the work by scope so the direction gate is matched to the size of the build. ## Cast and paint are two sizes of the same gate

[`cast`](https://github.com/AThevon/genjutsu/blob/08a792f6403104a231fc3f9b1612577698d6e03d/skills/cast/SKILL.md) runs a seven-stage pipeline for focused motion work; [`paint`](https://github.com/AThevon/genjutsu/blob/08a792f6403104a231fc3f9b1612577698d6e03d/skills/paint/SKILL.md) assembles a whole visual universe and keeps a persistent, stack-aware `MASTER.md`. Both pause at thesis, variant and identity gates — meaning the agent must present its creative intent and get sign-off before mutating state.

## Approval artifacts carry qualities that prose cannot

At a gate the user can request a live artifact with real motion and contrast data, a temporary preview route in the target stack, or an inline description. The point of offering a *medium* instead of a sentence is that motion, timing and contrast are properties that only a running artifact can let someone judge — direction cannot be fully verified in prose. Those preview files are intentionally throwaway; the durable authority is the repository's actual source plus the generated design-system files.

## No second authority outlives the build

There is deliberately no parallel design document that persists as a second truth: approved previews die, `MASTER.md` persists as the stack-aware design-system record, and the bundled `ui-ux-pro-max` data stays an acknowledged upstream module rather than becoming a separate genjutsu product. The decisive move is that the model's taste is externalized into an approval checkpoint the human can inspect and override before any mutation becomes real.
