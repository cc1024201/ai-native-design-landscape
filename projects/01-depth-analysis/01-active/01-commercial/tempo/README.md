# Tempo

Tempo's answer is that design lives in a Git repository, not on a canvas: the product's [own introduction](https://docs.tempo.new/introduction) calls it an "AI software factory" over five surfaces — Docs, Canvas, Issues, Chat and Agents — whose durable center is the branch-scoped local codebase. A Canvas storyboard is typed React source committed with the repository; a pushed branch or reviewed PR, not an agent's "done" state or a correct iframe, is the portable receipt of a design change.

That single decision determines every mechanism. A Canvas frame is a live iframe projection of a real route or React component, and the shipped `index.canvas.tsx` file under `tempo/designs/canvases/` is what commits to Git like any source. Returning an edit to source is deliberately strong: annotations (`data-tempo-filepath`, `data-tempo-position`, `data-tempo-source-version`) carry a file, byte address and observed source version into a React-aware projection, and the write pipeline does optimistic mtime-checked writes, three-way merges, conflict refusal and reverse-order batch rollback — an optimistic source transaction over local files, not a Git transaction.

**Two visual planes, not two source maps.** The embedded Browser is a separate, heuristic plane: its picker returns a CSS selector, DOM excerpt, geometry and computed styles, never a file/range/revision identity. Web Clipper and Figma paste similarly produce new authored storyboards derived from a page or design, not reverse pointers back to the original website or Figma node graph. Files and DOM are two different things here, by construction.

**Agents fit the code-first model.** Chat and background Agents do broader work in isolated Git worktrees on throwaway branches that must be reviewed, committed and merged, while Docs, Issues and chat history live in the organization database rather than the repository. The 2026 migration from the hosted Web editor to the desktop app is a deliberate authority reset — after transfer, the local/remote Git repository is the code lineage, and a ZIP proves file export, not continuity of hosted history.

With the current core closed and inspectable only as the pinned `Tempo.Setup.0.0.91.exe` distribution, the evidence unit is an immutable release plus official version history rather than a public commit.
