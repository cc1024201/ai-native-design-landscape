# Data Formulator

Data Formulator treats visualization design as a conversation over data and semantic chart specifications rather than a one-shot render. Microsoft Research's tool does not behave like a generic analytics chatbot that returns a picture: the agent produces structured chart artifacts a person can directly encode, restyle, compare and retain, and it works against the data itself, not just the pixels. [ChartRenderService.tsx](https://github.com/microsoft/data-formulator/blob/5d4f7b32b41888c21ca345742cdc1e6abb566d7f/src/views/ChartRenderService.tsx) projects semantic chart descriptions through supported visualization backends, so the stored object is a specification that several renderers can realize — the durable design is the semantic chart, not the screenshot.

The agent layer is split along the same line. A unified [analyst agent](https://github.com/microsoft/data-formulator/blob/5d4f7b32b41888c21ca345742cdc1e6abb566d7f/py-src/data_formulator/analyst/agent.py) composes tools and skills for data and visualization work, while a specialized [chart restyle agent](https://github.com/microsoft/data-formulator/blob/5d4f7b32b41888c21ca345742cdc1e6abb566d7f/py-src/data_formulator/agents/agent_chart_restyle.py) transforms Vega-Lite style intent and deliberately strips embedded data from the prompt before returning both a specification and a configuration UI — separating "how it looks" from "what it shows" as distinct operations.

Generation does not erase direct authoring. The [EncodingShelfThread.tsx](https://github.com/microsoft/data-formulator/blob/5d4f7b32b41888c21ca345742cdc1e6abb566d7f/src/views/EncodingShelfThread.tsx) binds hand-set encoding choices to the agent thread, and [ChartVariantStrip.tsx](https://github.com/microsoft/data-formulator/blob/5d4f7b32b41888c21ca345742cdc1e6abb566d7f/src/views/ChartVariantStrip.tsx) preserves alternative chart directions side by side. The resulting decision model is branching rather than mere undo: a user can ask for a different chart or edit from an existing point and keep sibling outcomes in the workspace for comparison. Persistence matches that — [useAutoSave.tsx](https://github.com/microsoft/data-formulator/blob/5d4f7b32b41888c21ca345742cdc1e6abb566d7f/src/app/useAutoSave.tsx) debounces a Redux workspace snapshot, scrubbing secrets and transient fields, while [sessions routes](https://github.com/microsoft/data-formulator/blob/5d4f7b32b41888c21ca345742cdc1e6abb566d7f/py-src/data_formulator/routes/sessions.py) define local, Azure and ephemeral storage plus workspace ZIP import/export. The boundary holds at the end: charts may resolve to Vega-Lite, ECharts or Chart.js, but rendered images are derivatives, and a successful render is not evidence an analytical conclusion is correct.
