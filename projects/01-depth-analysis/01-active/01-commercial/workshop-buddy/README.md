# Workshop Buddy

Workshop Buddy treats "design" as *solution design* — the work of turning a live discovery conversation into a governed, versioned specification of what should be built. It does not draw screens; it assembles a decision trail. The act it calls design is taking messy facilitator-and-stakeholder talk, committing the accepted pieces to a board, and letting coordinated agents expand that accepted state into architecture, KPIs, roadmap, executive story and an application spec. Its own vocabulary makes the boundary explicit: the durable unit is not the agent canvas but the *linked set of accepted evidence, generated artifacts and retained revisions*.

The mechanism is built around an explicit human commit gate. [transcript-intake.ts](https://github.com/jamesbas/WorkshopBuddy/blob/43ae1da9fbfcfd2db9c8d39f13bdb50661b2b351/innovate-impact/src/lib/agents/transcript-intake.ts) converts pasted or uploaded transcripts into candidate cards with quotes and confidence — but extraction never silently writes them into the workshop board. A facilitator edits and accepts each card, so the board is the agreement, not the model's claim.

From that accepted board, an [orchestrator.ts](https://github.com/jamesbas/WorkshopBuddy/blob/43ae1da9fbfcfd2db9c8d39f13bdb50661b2b351/innovate-impact/src/lib/agents/orchestrator.ts) runs eleven agents in a dependency-aware dependency chain: pain points and impact gate architecture, which gates KPIs and roadmap and story and spec. JSON schemas constrain outputs, and custom instructions are shared deliberately across the run. Authority flows forward from the committed evidence.

Regeneration preserves that authority rather than overwriting it. The [Prisma schema](https://github.com/jamesbas/WorkshopBuddy/blob/43ae1da9fbfcfd2db9c8d39f13bdb50661b2b351/innovate-impact/prisma/schema.prisma) persists projects, agent runs, artifacts and `ArtifactVersion` records; the regeneration route calls the same orchestrator and advances the artifact, keeping history. Markdown, DOCX and PPTX renderers are only delivery projections off that stored authority — the [artifact workspace](https://github.com/jamesbas/WorkshopBuddy/blob/43ae1da9fbfcfd2db9c8d39f13bdb50661b2b351/innovate-impact/src/components/artifact-workspace.tsx) remains the editable center.

In short: this is delegated solution design with review gates — evidence → accepted board → coordinated generation → versioned, editable artifacts → executor and executive delivery. "Design" lives in the accepted, versioned decision record, not in a pixel.
