# tldraw SDK / Agent Starter Kit

tldraw answers "what is design" not with its visual editor but with the store underneath it. The design is a typed reactive record graph — a `TLStore` of pages, shapes, bindings, assets and document metadata governed by a schema — and rendering is only a projection of those records. The agent therefore does not infer a drawing from pixels or replace the canvas with a generated image; it reads and changes the same structured graph the user is editing (revision [`c47a5bd9`](https://github.com/tldraw/tldraw/tree/c47a5bd9ff3b923279253b4a286512ec7eb7f0d2)).

The decisive mechanism is that human and agent share one authority boundary. The official Agent Starter Kit demonstrates the intended loop: the application gathers canvas context, the model proposes actions, typed action utilities validate or interpret them, and the `Editor` API applies operations such as create, move, resize, label, align, distribute or review. The checked-in `templates/agent/client/actions/` directory makes this an inspectable implementation surface rather than a generic "AI ready" claim — concrete canvas operations you can read. A user can select or move a generated shape and then ask the agent to reason about the updated graph, which is what makes the loop correctable; it is also what makes stale context a real risk, since a host must decide what happens if a human changes records after the model plans but before the actions apply.

The mutation surface is deliberately narrow: many small action types rather than one unrestricted script executor, narrowing and describing what the agent may touch, though security and approval semantics remain the embedding application's responsibility. Persistence is deliberately a host choice — `persistenceKey` for IndexedDB and same-browser tab sync, document snapshots, a custom backend, or `@tldraw/sync` for multiplayer rooms ([persistence](https://tldraw.dev/docs/persistence), [sync](https://tldraw.dev/docs/sync)). An agent action is durable only to the degree the host actually persists the store. This is visual-editor infrastructure with an implemented AI canvas loop, not a claim that tldraw.com itself exposes every starter-kit capability.
