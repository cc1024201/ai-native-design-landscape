# Gamma

Gamma answers "what is design" by collapsing the tools that usually separate it: a presentation, a document and a webpage are not three products but three delivery modes over one ordered card graph. Its [card contract](https://help.gamma.app/en/articles/11016396-what-are-cards-in-gamma-and-how-do-they-work) calls cards the fundamental building blocks of all three, letting a card behave as a flexible slide, a section or a canvas, grow with content or stay fixed-ratio. There is no separate design file that a deck then gets exported from; design *is* the card graph, and presenting, publishing and exporting are projections of it.

That single-authority structure is what makes the AI mechanism distinctive. [Starting](https://help.gamma.app/en/articles/7838093-how-do-i-create-a-new-presentation-document-or-webpage-in-gamma) from a topic, pasted text, file or URL all converge on the same graph, so the AI has no privileged input surface — it proposes edits that land in the same native cards a person edits by hand. Agent work is scoped before it is adopted: one card gets a preview-then-apply edit, a new card is inserted with a position, and a whole-artifact bulk edit waits behind an explicit `Accept all`. The boundary is a run-state one too, with AI editing blocked while generation is still running.

The most interesting part of Gamma's model is not the visible card but the invisible governance layer. [Template instructions](https://help.gamma.app/en/articles/16056626-what-are-template-instructions-and-how-can-i-use-them) travel with a saved template, are fed into the AI prompt and never appear in the generated deck; a card marked locked is guidance to the model rather than a permission for humans. So three authorities coexist — visible content, the theme/template structure, and hidden generation instructions — and a visual review of output cannot recover the generation policy. Copying a template manually doesn't carry the instructions either; the governance only acts on the AI path.

Versioning is similarly layered rather than one universal undo. [Undo, hidden cards and version restore](https://help.gamma.app/en/articles/11048579-can-i-undo-a-change-or-restore-a-previous-version-in-gamma) solve different problems: undo reverses recent operations, a hidden card keeps backup material inside the artifact but out of delivery, and restore replaces current state with an earlier snapshot. Nested inside all of this, [Imagine](https://help.gamma.app/en/articles/13928852-what-is-imagine-and-how-do-i-design-with-it) is a separate AI graphic canvas whose finished pieces flatten to media in a card — its edit history is not the card history. Design here means managing card-level structure and the nested artifacts it composes, knowing that sharing roles, published copies and exports are [permissioned projections](https://help.gamma.app/en/articles/11047226-how-do-collaboration-and-sharing-settings-work-in-gamma) that can go stale relative to the live graph.
