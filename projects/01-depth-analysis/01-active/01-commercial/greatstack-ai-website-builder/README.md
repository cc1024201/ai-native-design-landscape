# GreatStack AI Website Builder course project

GreatStack's AI Website Builder treats design as a **versioned HTML document**, and everything else — prompt, preview, source view, save, publish — is a way to advance or promote one adopted version. The product is a course artifact: the [official project page](https://greatstack.dev/p/sitebuilder) links the source, assets, preview Figma design and course video and claims more than two thousand builders, but the official download is gated, so the implementation is read through public learner mirrors that share an exact fingerprint (same schema fields, migration shapes, prompt copy and controller routes across ninety-eight repositories).

The mechanism it teaches is explicit and unglamorous, which is the point. A representative mirror's [`schema.prisma`](https://github.com/rizwanullah-dev/AI-website-builder/blob/600a9e34a883fed12805187fd90b79bc78bd2ace/server/prisma/schema.prisma) separates projects, conversations and versions and records the selected version plus publication state; [`projectController.ts`](https://github.com/rizwanullah-dev/AI-website-builder/blob/600a9e34a883fed12805187fd90b79bc78bd2ace/server/controllers/projectController.ts) streams model generation and revision into complete HTML versions with rollback and public-page transitions. A representative [`ProjectPreview.tsx`](https://github.com/rizwanullah-dev/AI-website-builder/blob/600a9e34a883fed12805187fd90b79bc78bd2ace/client/src/components/projects/ProjectPreview.tsx) renders the current document and supports element targeting, while source editing, download and publication promote an adopted version — none of these are implicit side effects of a prompt. Design is therefore not an ephemeral generation; it is a committed version in a graph you can roll back, select and ship. [Official course video](https://www.youtube.com/watch?v=kfcnYB0sQbM) · [GreatStack GitHub organization](https://github.com/GreatStackDev)

The durable artifact is the complete HTML version plus its version records. This is a teaching product about making AI-generated UIs reviewable and persistently shippable, and its value is the versioned promotion loop, not a proprietary runtime or a fancy design graph.
