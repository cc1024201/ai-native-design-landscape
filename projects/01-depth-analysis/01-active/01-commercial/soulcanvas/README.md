# 灵境画布

灵境画布 defines design as the creative process made into retained project data. Its answer to "what is design" is not the finished image or video — it is the whole run: references, plans, intermediate results and lineage kept beside the final media on an infinite canvas. The act of design is a continuing, inspectable lineage rather than a one-shot download.

## Design is Agent mode made observable

The user places product images, visual references, notes or video on an infinite canvas and chooses free creation or Agent mode. In Agent mode the system shows its analysis, plan, tool calls, progress and expected credit cost; each step can be inspected, paused, retried or continued — the model isn't a black box but a visible executor. [Agent and canvas mechanism](https://soulcanvas.cn/#features)

## One result becomes the next input

The decisive mechanism is that generated results return to the canvas automatically and can be arranged, grouped, compared and selected for another operation (retouching, a sibling image, or image-to-video). A result is an input node in a continuing lineage, not a disposable artifact. The first-party product states that prompts, reference material, agent plans, generated results and version relations are retained when the project is reopened — persistence of the whole process is the strongest differentiator here. [Workflow](https://soulcanvas.cn/#workflow) · [product surface](https://soulcanvas.cn/)

Public evidence does not disclose how nodes are serialized, whether history branches internally, or which model providers execute each operation. A `.cn` domain and Chinese-language surface are discovery context, not geography evidence.
