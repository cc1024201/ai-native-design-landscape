# Opsiforce

Opsiforce defines "design" as an application build *inside an owned environment*, not as pixels or prompts. Design here is whatever the agent and the user produce together in real source under `/workspace/app`, and the platform's distinction is that it wraps that source in a durable, isolated, Kubernetes-native shell rather than owning the artifact itself. The operative contract is the agent definition at [`agent-config/agents/app-builder/agent.md`](https://github.com/SimaDevelopment/opsiforce/blob/eecd19ebe2b5ea7df56b94abd5be659115ab8c82/agent-config/agents/app-builder/agent.md): install and edit in `/workspace/app`, use a Vite frontend plus NestJS backend, persist app data in SQLite, type-check, boot the services, and walk the real user flow with a browser before declaring the app ready.

The decisive mechanism is that the agent mutates genuine project state that persists across pod replacement — the project volume preserves source, Git history, agent session state, application databases, uploads, and IDE settings — while a separate read-only SQLite observability database records requests, process output, and lifecycle events purely to diagnose the app, never as part of its data authority. Preview and production are distinct environments: development hot-runs behind environment-specific runtime proxies, while publication uses Git to copy tracked source into Production (or another target) while retaining that environment's database and configuration. An idempotent migration at [`migrations/20260608_production_publish_support/migrate.mjs`](https://github.com/SimaDevelopment/opsiforce/blob/eecd19ebe2b5ea7df56b94abd5be659115ab8c82/agent-config/agents/app-builder/migrations/20260608_production_publish_support/migrate.mjs) converts generated projects to production build/start scripts and a Vite preview binding.

What this makes concrete is a control-plane posture: the NestJS control plane, Go runtime proxies, agent/skill configuration, Helm charts, and migrations are all in the open repository, so generation, runtime, persistence, and publication can be traced at the source level rather than inferred from a hosted UI. The agent and the user share one environment-owned source tree, and the platform supplies the preview routing, code/database surfaces, observability, and environment promotion around it.
