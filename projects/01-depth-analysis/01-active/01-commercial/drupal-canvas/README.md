# Drupal Canvas

> Research status: **Source-level** · Lifecycle: **active** · Last reviewed: **2026-08-12**

Drupal Canvas is Drupal's browser-native site and page builder; its hidden Canvas AI submodule adds agents to the same component and entity authority.

## Pages are structured component trees

The editor composes reusable server and JavaScript components into Canvas page entities and structured-content templates. Autosave, draft rendering, entity revisions, permissions, translation, personalization, and publication remain Drupal concerns rather than model-session state.

## AI operates through explicit host tools

Configured orchestrator, page-builder, component, template, metadata, and title agents call functions to inspect layout and entity context, place or edit components, create field content, change page values, and verify completion. Props schemas and component catalogs constrain those mutations.

## One artifact supports visual and headless delivery

The same stored component tree drives the browser editor and published rendering, with headless packages projecting it into supported frontend frameworks. Canvas AI does not own a parallel document; it writes through Drupal's page and component model.
