# Adobe Firefly Creative Agent

Adobe Firefly's creative agent defines design as **delegation with retained host authority**: design is a multi-step creative task that an agent plans and executes, but the produced artifact stays governed by the native document of whatever host the work lands in. The agent answers to intent, not to a new file format — there is no Adobe-owned design type that supersedes the document being worked on. [Evidence: Adobe announces the creative agent](https://news.adobe.com/news/2026/04/adobe-new-creative-agent)

The decisive mechanism is external-agent orchestration **across established visual authorities**. One agent lineage plans the work, can invoke different models for different steps, and is expanding from Firefly into Premiere, Photoshop, Illustrator, InDesign and Frame.io (After Effects and parts of the unified Firefly creation surface remain at earlier access stages). A Photoshop, Illustrator, InDesign or Premiere file remains governed by its host's native editing semantics; the agent coordinates operations *over* those authorities rather than replacing them. [Evidence: expansion across Creative Cloud](https://news.adobe.com/news/2026/06/adobe-unveils-major-expansion)

Two adjacent surfaces clarify where the tool's own authority begins and ends. In Firefly, Projects and the unified creation surface give a managed workspace around generated and edited assets. Firefly Creative Production adds a no-code modular workflow that defines inputs, processing and outputs for batch asset production and review — operational automation whose resulting creative files are still just deliverables, not a fused workflow-document. [Evidence: Creative Production FAQ](https://helpx.adobe.com/enterprise/using/firefly-creative-production-faq.html)

The evidence ceiling is honest: April and June 2026 announcements distinguish public beta, private beta and expanded availability, so the census records `active-transition` rather than treating every announced surface as generally available. Public material establishes user-visible orchestration and host scope, not the internal planning graphs, tool-call protocols, cross-app transactionality or shared version model.
