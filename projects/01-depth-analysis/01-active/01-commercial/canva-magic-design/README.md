# Canva Magic Design

Magic Design's durable answer to "what is design" is the transfer from *generated directions into a native Canva design that stays editable and deliverable through the rest of Canva*. It has evolved from a 2023 template picker through Magic Studio into Canva AI and the 2026 [Canva AI 2.0](https://www.canva.com/newsroom/news/canva-create-2026-ai/) research preview, but the product idea is not one model or one label — it is candidate-generation gated by explicit promotion into an editable native document.

The decisive mechanism is the promotion boundary between a candidate and the design. The [MCP verification guide](https://www.canva.dev/docs/mcp/verify-integration/) encodes the same contract the original product promised: `generate-design` returns candidates, the user selects one, and only `create-design-from-candidate` yields a real Canva `design_id` with edit links. Automatic candidate selection and fabricated ids are listed as mistakes — a previewed direction becomes user-owned only after selection. This keeps candidate thumbnails, generated media and the eventual design distinct.

Editability is layered and transaction-gated. Canva AI 2.0's [Design Model](https://www.canva.com/newsroom/news/canva-create-2026-ai/) generates from individual objects with layout, hierarchy and brand — "change only the headline" is meant to preserve everything else. The [MCP tool catalog](https://www.canva.dev/docs/mcp/tools/) exposes a four-step `start-editing-transaction → perform-editing-operations → commit/cancel` protocol, where operations stay draft until commit and concurrent browser edits can stale the session. [Magic Layers](https://www.canva.com/newsroom/news/magic-layers/) runs the inverse path — reconstructing a flat image into live text boxes, movable objects and preserved layout — which is semantic reconstruction, not source recovery.

Persistence is federated around the native design rather than a single ledger. The [Connect API](https://www.canva.dev/docs/connect/canva-concepts/) exposes candidate ids, design ids, page ids, transaction ids, element ids, asset ids, brand-template ids and export job ids as distinct, non-interchangeable identities; brand Kit/template, memory, connectors and delivery each keep their own divergence boundary, and no public operation rewinds them all atomically. The [design-edit handoff guide](https://www.canva.dev/docs/mcp/workflows/design-edit/) states the acceptance rule plainly: an agent workflow is not done after export — it returns the edit URL so the person continues in Canva. Design, in other words, is a layered, editable, human-owned center with generation and delivery as its edges.
