# HyperFrames

HyperFrames is explicit where most motion-AI tools are vague: design is a time-addressable browser composition — authored HTML, CSS, media and animation — and video is only what it renders to. The [core skill](https://github.com/heygen-com/hyperframes/blob/7860d19433e45507c9544f6e6b542e7e572e47c9/skills/hyperframes/SKILL.md) is built so an agent does not hand a text-to-video model a paragraph; it plans and writes inspectable motion source in the project, then materializes frames from it deterministically.

The decisive mechanism is that the browser composition, not the MP4, owns the design. The pipeline runs brief/assets through an agent-written animated HTML source, then through lint, inspection and browser preview before deterministic frame production encodes an MP4 — and correction loops restart from the source, not from the render. The monorepo makes each stage executable rather than abstract: [`producer.ts`](https://github.com/heygen-com/hyperframes/blob/7860d19433e45507c9544f6e6b542e7e572e47c9/packages/cli/src/utils/producer.ts) coordinates frame production, and the studio server exposes [preview](https://github.com/heygen-com/hyperframes/blob/7860d19433e45507c9544f6e6b542e7e572e47c9/packages/studio-server/src/routes/preview.ts), [lint](https://github.com/heygen-com/hyperframes/blob/7860d19433e45507c9544f6e6b542e7e572e47c9/packages/studio-server/src/routes/lint.ts) and [render](https://github.com/heygen-com/hyperframes/blob/7860d19433e45507c9544f6e6b542e7e572e47c9/packages/studio-server/src/routes/render.ts) routes as separate feedback surfaces — a successful export is not treated as the only signal.

That split exposes the source-versus-delivery asymmetry at the heart of the project: the HTML project keeps editable structure, media references and animation semantics, while a rendered MP4 preserves pixels and timing but not DOM editability. Design authority stays in the authored source; the video is a projection of it. Versioning is consequently ordinary filesystem and Git history rather than a hosted design graph. Apache-2.0 licensed under HeyGen, HyperFrames is a sharp counterpoint to black-box motion generation — it trades the illusion of "design by prompt" for a fully inspectable, re-renderable design artifact.
