# Relume

Relume answers "what is design" as structured pre-production convergence rather than pixel mutation. The design act is building and agreeing on a linked sitemap/wireframe/section graph long enough for a team to settle structure and copy, after which Relume generally stops being the mutation authority and consciously promotes a chosen destination — Figma, Webflow, React/HTML, Claude Design or pricing Excel — to source of truth ([docs](https://resources.relume.io/resources/docs/building-a-sitemap-with-ai)). "The project has a style guide" does not mean every exit transports it: the React path exports unstyled wireframes and the separate Claude path packages the design system but omits the wireframe graph.

The decisive mechanism is constrained component search over a maintained corpus. Generation quality comes less from freeform drawing than from selecting and configuring components; Wireframing 2.0 weighs section title, description, content count and a layout family while searching the marketing library ([May 2026 release](https://www.relume.ai/whats-new/may-2026-release)). In the editor, variant swap, replace, reset-structure-vs-reset-copy, family styles and global sections all mutate the same hosted component graph at bounded risk — deleting a button is a structural operation, while asking AI to reinterpret a section may change component choice, copy and layout. Style concepts are a conditional projection (an approximate 80% accelerator, not final fidelity), and Design View applies a chosen guide while exact spacing and polish remain destination work.

The artifact is a coupled host project in which each sitemap section is directly linked to a wireframe section, so deleting either side deletes the counterpart and a section's title/description forms the "section prompt" for component selection. Persistence is fragmented across at least four paths: Site Builder's custom delta protocol, a newer Yjs-backed Publish artifact ([client bundle](https://www.relume.ai/app/_account/js/index.d39898cd.js)), and exits that deliberately detach (Figma import breaks library propagation) or reconcile (Webflow class/component schema). The [Library MCP](https://www.relume.ai/relume-library-mcp) is a component faucet for external coding agents — searched by slug and vendored — not an agent interface to a Site Builder project, which staff confirms is unreachable. Relume is a planning graph that forks into destinations with independent clocks, moving toward a second hosted authority in Publish where brief → component graph → deployment stays inside Relume.
