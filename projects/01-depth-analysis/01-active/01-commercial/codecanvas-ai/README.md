# CodeCanvas AI

CodeCanvas AI treats design as editing real project source from the canvas: it places multiple live application frames on a visual IDE surface while keeping a code editor, chat, Git branches, assets and history around them, and the project files inside branch workspaces are the canonical authority. Design is not a mockup — it is whatever the running frames render from actual code, and clicking a visual element is meant to resolve back to a file and source range.

The implementation hinges on how that click resolves. Rendered nodes carry [injected object IDs, and the tool reconciles the DOM with an AST index](https://github.com/FaridDevU/CodeCanvas-AI/tree/fc731386f70d3c4e0f76de3c128bbf607dcfd04d/design-editor-src/src/components/store/editor/ast): the DOM shows the live tree but hides which JSX component instance produced a child, while the AST knows file ranges, components and instances but not the final runtime tree. A documented algorithm walks both, using parent-child component changes and index matching to recover an instance location. The match is deliberately constrained — it can fail for dynamic trees, fragments, generated content or unsupported syntax, and the code falls back when it cannot locate a safe range.

Once a range is found, mutation is range-bounded and deterministic: [the HTML source writer](https://github.com/FaridDevU/CodeCanvas-AI/blob/fc731386f70d3c4e0f76de3c128bbf607dcfd04d/design-editor-src/src/lib/html-source-writer.ts) parses source and uses `MagicString` to update attributes, inline styles, text, removal and insertion for the identified node, preserving or migrating CodeCanvas IDs and rejecting operations that cannot be represented safely. Broader JSX edits route through the editor engine and agent path rather than pretending every HTML operation generalizes. Selected elements also [refresh chat context with the owning file, highlighted code and branch metadata](https://github.com/FaridDevU/CodeCanvas-AI/blob/fc731386f70d3c4e0f76de3c128bbf607dcfd04d/design-editor-src/src/components/store/editor/chat/context.ts), so an agent request reads current content, not a stale initial snapshot. Authority stays with branch-scoped project files; the canvas, editor and agent all write the same source.
