# Pilot Marketing AI Design System

> Research status: **Source-level** · Lifecycle: **active** · Last reviewed: **2026-08-12**

Pilot's public marketing system is a first-party brand authority prepared for direct agent consumption. The product here is not an autonomous agent; it is the structured, owned artifact that keeps human and AI-produced marketing work inside the same visual language.

## One Markdown document is canonical

[`pilot-design-system.md`](https://github.com/Pilot-Design-Team/pilot-ai-design-system-marketing-public/blob/1b33cff0ee51730877bbf9b85f5996a07504d341/marketing/pilot-design-system.md) declares colors, typography, spacing, components and brand rules. The repository places it beside fonts, icons, logos, imagery and presentation guidance. A dedicated HTML viewer and visualizer project the document for humans without creating another authority.

```text
canonical design-system Markdown + approved assets
-> human or coding agent generation
-> visualizer / page / slide output -> review against same contract
```

The system does not automatically lint or write generated artifacts, so enforcement depends on the consuming agent and reviewers. Git history provides system versioning; generated pages or decks live in their own project. A synchronization workflow prepares the same source for skill distribution rather than asking teams to maintain divergent copies.
