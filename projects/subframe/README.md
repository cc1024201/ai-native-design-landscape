## Scope

An AI-native design tool oriented around production-ready UI and code-aware design workflows.

## Technical direction

- Uses real component/code concepts as a bridge between design and implementation.
- Exposes design context to coding agents through MCP.
- Treats reusable design-system components as primary design building blocks.
- Targets production-ready frontend output rather than image-only mockups.

## Public technical choices

- Surface: visual design editor.
- Integration: MCP for external agents.
- Artifact: structured UI/design plus production-oriented code.
- Design system: reusable component library and styling context.
