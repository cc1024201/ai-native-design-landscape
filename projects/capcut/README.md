## AI generation is one entry into a much larger project

CapCut's Video Studio can create a draft through chat including style and avatar choices. The same product exposes conventional editing on online desktop mobile and tablet surfaces: clips captions audio voice images transitions effects and templates continue as editable project state. An export is the flattened delivery not the whole Design artifact.

AI operations include script and media generation captioning speech and voice tools background and object manipulation and image editing. Each has a narrower target inside the project. Public marketing does not establish that a single autonomous agent can mutate every property or that all device clients share an identical project schema so the census records the ordinary convergence without inflating orchestration claims.

Dreamina and Pippit are linked from CapCut but maintain their own names workspaces and product contracts. Shared ByteDance organization does not make them duplicate products.
