# Taste-Skills

> Research status: **Source-level** · Lifecycle: **active** · Last reviewed: **2026-08-12**

Taste-Skills turns visual judgment into separable agent operations: screenshot surgery and visual audit establish observations; design ranking compares candidates; critique and rationale convert those observations into decisions a team can act on.

## Evaluation precedes mutation

The product does not own the implementation canvas. It reads screenshots or existing interfaces, records hierarchy, typography, color, rhythm and interaction evidence, then produces a review or ranking. Host source and design files remain authoritative and human review is explicitly required.

That report-and-decision loop distinguishes the project from a passive inspiration catalog, while its experimental status limits any claim of professional validation.
