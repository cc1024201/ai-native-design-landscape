## A PowerPoint template becomes a governing input

OkkSlides accepts source files and assets for research and presentation generation. More distinctively it imports a `.pptx` template and claims to learn fonts colors and layouts so subsequent decks follow that system. An existing deck can also be uploaded for layout typography and visual redesign without replacing its content purpose.

The resulting canvas exposes direct text image chart table position scale and rotation edits. Natural-language requests can revise layout or styling while the user retains element-level control. Export materializes the result back into editable PowerPoint rather than flattening each slide.

The public page does not describe whether uploaded template rules are stored as explicit tokens masters or generated examples. It also does not establish a bidirectional live link after PPTX export. The handoff should therefore be read as a transfer from OkkSlides' hosted graph to native PowerPoint objects.
