# Scott's Dope Skills

> Research status: **Source-level** · Lifecycle: **active** · Last reviewed: **2026-08-12**

Scott's Dope Skills is counted through a connected frontend Design subsystem: it can elicit a USERS.md, author and lint a DESIGN.md, build or polish an interface, produce prioritized UI/UX critiques and route those findings into a repeatable correction loop.

## Durable briefs let critique recur

`grill-users` and `grill-design` turn conversational choices into repository artifacts. UI and UX critics then evaluate implementation against those contracts, while `critique-loop` can convert findings into tracked work and re-run the same review until it converges or reaches a stop condition.

The collection is one maintained product boundary. Its many non-Design engineering skills are not counted separately and do not enlarge the Design claim.
