## AI sits inside a product-development system

Mercer stores inspiration sketches CAD files tech packs images video 3D files spreadsheets and generated concepts in collections. Its AI Designer creates concepts variations text-to-image results and paintbrush edits while custom Influences use past collections or reference boards to constrain visual direction.

Measurements notes comments tasks timelines and reviews attach production judgment to the same records. Designs can be shared with manufacturing partners through collection links or print-ready PDFs. Enterprise customers may also use Mercer's production network but the software remains usable with a brand's existing manufacturers.

The current site explicitly states “Formerly Cala” so this is one product transition rather than a new team. Public material does not reveal revision granularity tech-pack schema model-training interface or whether print-ready exports can round-trip. AI images are concept artifacts and should not be mistaken for production patterns by default.
