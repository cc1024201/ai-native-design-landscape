## Scope

Google's AI-native software design canvas for generating, iterating and steering high-fidelity interface designs.

## Technical direction

- Centers design work on a persistent AI-native canvas.
- Supports real-time steering rather than one-shot prompt generation.
- Accepts natural-language and multimodal design context.
- Connects design exploration to downstream software-building workflows.

## Public technical choices

- Surface: AI-native/infinite design canvas.
- Agent: persistent design agent with real-time iteration.
- Inputs: natural language, voice, images/design/code context.
- Outputs: high-fidelity UI and shareable/implementation-oriented artifacts.
