# Atlas Design UX Team

> Research status: **Architecture-level** · Lifecycle: **active** · Last reviewed: **2026-08-12**

Atlas Design UX is an independently installable team inside the Atlas Agent Teams marketplace. Five roles cover research, UX, UI, interaction and review while one orchestrating command advances discovery, planning, execution, review and summary.

## Team state is observable but artifacts remain external

A team manifest defines roles and phases, command files coordinate handoffs, and a hook writes activity to a local team log. Skills specify user research, accessibility, design systems, wireframing and prototyping. Any Figma, Sketch, Adobe XD or code artifact is still owned by that external host; Atlas supplies the operating contract and audit trail.

The mixed top-level marketplace is excluded as one Design product. This component is counted because it has its own plugin manifest, commands, agents, skills, hooks and install route.
