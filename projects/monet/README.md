## Scope

A local-first AI video/editor experiment combining a real timeline/canvas with coding agents and local tool interfaces.

## Technical direction

- Uses a domain-specific professional editor as the visual surface for general coding agents.
- Keeps timeline/preview state visible while agents operate through local interfaces.
- Explores the same agent-plus-visual-surface model outside web UI design.
- Targets local-first workflows.

## Public technical choices

- Surface: video timeline + preview/canvas.
- Agent integration: local API/MCP/terminal-oriented workflow.
- Artifact: editable media/project state.
- Implementation: public repository.
