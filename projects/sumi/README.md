# Sumi

> Research status: **Source-level** · Lifecycle: **active** · Last reviewed: **2026-08-12**

Sumi is a routed UX/UI design system for Claude Code that joins research, visual direction, wireframes, production components, Figma transfer, accessibility, critique and launch checks. Its product boundary is not the size of its reference corpus, but twelve gated pipelines and a persistent design-memory contract shared by make, review and planning commands.

## `.sumi/` is the decision memory

Briefs, style tokens, screen maps, quality scores and an append-only decision log persist in project files. Later commands read those records instead of reinventing palette, audience or constraints. A create route can advance from brief to style, wireframe and production screen; audit and fix routes produce evidence, patches and before/after comparison before a quality score is accepted.

Sumi also records which empirical claims are verified or still untriaged. Structural validators protect routing and schemas, but the project explicitly says those checks do not prove the design advice is correct—an important boundary between software validity and design judgment.
