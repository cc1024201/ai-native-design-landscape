# ives

> Research status: **Source-level** · Lifecycle: **active** · Last reviewed: **2026-08-12**

ives packages Design as contextual judgment rather than a fixed style recipe. Thirteen composable skills reason from user intent and information density through hierarchy, typography, color, interaction and critique.

## The critique is the durable boundary

The decisive workflow uses four lenses—visual design, interface design, interaction consistency and user context—to identify specific issues and coordinate changes with implementation-oriented skills. It can steer generation and review, but it does not own a renderer or a proprietary canvas; the host project's source remains authoritative.

This inclusion is therefore for an operated reasoning and review system, not for the repository's philosophy claims in isolation.
