## Scope

A modular open-source visual editor framework for React that can be embedded into products needing drag-and-drop/direct-manipulation authoring.

## Technical direction

- Provides reusable visual-editor primitives instead of a complete AI agent product.
- Lets applications expose their own React components as editable building blocks.
- Separates host application data/model choices from editor interaction mechanics.
- Can serve as a foundation for deterministic direct manipulation.

## Public technical choices

- Stack: React visual editor framework.
- Surface: embeddable drag-and-drop editor.
- Artifact: host-defined component/config data.
- Implementation: open-source package/repository.
