# Specula BOS

> Research status: **Architecture-level** · Lifecycle: **active** · Last reviewed: **2026-08-12**

Specula BOS is the product architecture that the Specula Method is meant to build. It organizes a brand as a living operating system across world futures identity exploration strategy governance interface and an ethical frame.

## Memory and refusal are product objects

At commit [`8544ca1`](https://github.com/oddtitoreal/specula-bos/tree/8544ca1b6a6a9fa8199ff7d391019430e05156a8) the open layer defines seven system layers a five-domain memory architecture a synthesis council workshop protocols and a Definition of Done. The [Brand Governance Playbook template](https://github.com/oddtitoreal/specula-bos/blob/8544ca1b6a6a9fa8199ff7d391019430e05156a8/templates/brand-governance-playbook.md) is the durable handoff.

The BOS distinguishes decisions scenarios refusals brand identity and context instead of flattening everything into conversation history. Agent onboarding makes values and governance readable to an AI participant without granting it final authority.

## Open architecture versus implementation

The repository explicitly withholds AI configurations prompt libraries operational facilitation tools and implemented JSON memory schemas. It therefore supports product and governance architecture claims but not a complete open runtime. Runtime contracts live in Specula Framework and the facilitation process in Specula Method; all are kept as separate products because the team itself assigns non-overlapping authority.

The team region follows the maintainer's Pesaro Italy profile.
