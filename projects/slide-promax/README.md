# Slide ProMax

> Research status: **Source-level** · Lifecycle: **active** · Last reviewed: **2026-08-12**

Slide ProMax is broader than its name: one agent skill can produce interactive app prototypes, browser decks, editable PowerPoint, motion, infographics and structured critique. It defines design as an explicit direction-and-review process backed by format-specific renderers.

## Human choice is a first-class state transition

For vague briefs the advisor generates at least three materially different directions, then waits for a choice. Brand work follows an asset protocol before production. HTML prototypes are exercised with Playwright; motion uses a stage-and-sprite time model; HTML decks can be translated from computed DOM styles into editable PowerPoint text and shapes.

The artifact authority therefore depends on the route: HTML/CSS for prototypes and browser decks, a native PPTX graph after translation, and frame/time source for video. Review sheets and critique reports help selection but are not themselves the design source.

The search surfaced the older `shield-design` repository, whose current README names and installs Slide ProMax. The separately named `DinhLucent/Slide_ProMax` repository is the current product source, so both surfaces count once.
