# Ki-Stack

> Research status: **Source-level** · Lifecycle: **active** · Last reviewed: **2026-08-12**

Ki-Stack teaches coding agents to choose among live KiCad Python IPC, official CLI rendering/checks and structured offline file surgery instead of hiding the application behind a large universal tool wrapper.

## Substrate skills precede domain skills

Orientation first discovers files and installed capabilities. File surgery is followed by render-after-edit, ERC/DRC and evidence reporting; PCB and schematic skills compose those lower-level operations. Live state uses `kicad-python`, while official exports and checks use `kicad-cli` and recoverable source changes can use `kiutils-rs`.

The stack retains native KiCad documents as authority. It is an operating method with helper scripts, not an independent geometry or electrical kernel.
