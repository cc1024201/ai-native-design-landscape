## A local executable project is the working design

Orbis turns a prompt or referenced website into multiple complete directions and runs them as live React and Tailwind prototypes in a sandbox on the user's machine. The canvas is not merely a bitmap preview: text images spacing and other selected elements can be edited inline and the running result updates in place.

The mechanism connects four representations without claiming they are identical:

1. local executable screens carry the interaction and layout;
2. `design.md` distills palette typography spacing motion and component conventions for reuse;
3. measured handoff reads tokens redlines and component notes from the rendered result;
4. Figma export materializes editable layers text styles components and assets for deeper design-tool work.

Parallel directions make exploration explicit. A direction can be promoted into the continuing project while the local project remains the executable reference. Journey maps are derived from actual screens rather than a manually redrawn flow.

## What is and is not established

The public surface strongly establishes local execution inline correction system extraction and editable Figma delivery. It does not publish the internal project database or prove lossless reverse synchronization after the Figma file is edited. The dossier therefore treats Figma as a delivery materialization and not a second authority.
