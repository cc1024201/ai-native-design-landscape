## Scope

An AI application builder with design-oriented visual controls and a dedicated Design Pack for refining generated applications.

## Technical direction

- Starts from generated working applications and adds structured visual refinement.
- Uses themes and design controls to maintain coherent styling across generated surfaces.
- Supports section-level redesign rather than requiring full regeneration.
- Keeps visual iteration inside the application-building environment.

## Public technical choices

- Surface: browser app builder with design controls.
- Editing: themes, visual redesign and section-level refinement.
- Artifact: generated application/site.
- Agent: natural-language build and modification workflow.
