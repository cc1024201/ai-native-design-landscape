# Archie

> Research status: **Source-level** · Lifecycle: **active** · Last reviewed: **2026-08-12**

Archie treats architecture work as governed enterprise decisions, not as the production of attractive diagrams. Its source combines an application-portfolio model, ArchiMate/TOGAF-oriented views, an AI architect, and review records.

## The model is larger than the picture

Applications, capabilities, dependencies, lifecycle attributes, and assessment data are first-class records. Diagrams are views over that portfolio. This makes the native graph and its governance metadata the authority; a visual export cannot substitute for the underlying enterprise model.

## AI proposes candidates into a review system

The AI path can analyze the portfolio and formulate candidate architectures or recommendations. Those proposals enter Architecture Review Board workflows rather than silently overwriting an approved state. Review status, rationale, and audit records are therefore part of the product mechanism, not administrative decoration.

## Why this is a distinct definition of design

Here, “design” means deciding how an enterprise system should evolve under standards, portfolio constraints, and accountable approval. The repository demonstrates that loop. It does not prove that every generated recommendation is operationally correct or that an exported view deploys infrastructure.
