# YUV.AI Creative Skills

> Research status: **Source-level** · Lifecycle: **active** · Last reviewed: **2026-08-12**

YUV.AI Creative Skills is a routed creative-production stack rather than a loose list of prompts. One installer supplies a brand system, cinematic decks, landing-page builders, video editing, short-form production and a director/orchestrator that chooses the appropriate workflow.

## A shared brand authority spans several executable artifacts

[`yuv-design-system`](https://github.com/hoodini/ai-agents-skills/blob/f7a43d8f852550a4f834240dc874cf9f56e7eec7/skills/yuv-design-system/SKILL.md) is the palette, typography and component authority. [`yuv-decks`](https://github.com/hoodini/ai-agents-skills/blob/f7a43d8f852550a4f834240dc874cf9f56e7eec7/skills/yuv-decks/SKILL.md) applies it to source-backed presentations; [`video-edit`](https://github.com/hoodini/ai-agents-skills/blob/f7a43d8f852550a4f834240dc874cf9f56e7eec7/skills/video-edit/SKILL.md) inserts a browser transcript-review surface before render; and [`yuv-pilot`](https://github.com/hoodini/ai-agents-skills/blob/f7a43d8f852550a4f834240dc874cf9f56e7eec7/skills/yuv-pilot/SKILL.md) routes cross-channel builds.

Projects persist under a defined filesystem root and versioned renders are not overwritten. The repository is one product because the visual system, installer and orchestration contract deliberately bind the media-specific skills into one stack.
