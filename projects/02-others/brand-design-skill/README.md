# Brand Design Skill

> Research status: **Source-level** · Lifecycle: **active** · Last reviewed: **2026-08-12**

Brand Design Skill defines AI brand work as a sequence of explicit human decisions, not a logo prompt. It starts from a Socratic brief, branches into structurally different image routes, locks one selected image and only then expands that source into final raster assets, applications and an editable HTML manual.

## Approval is part of the artifact model

[`SKILL.md`](https://github.com/ziguishian/brand-design-skill/blob/14aaa3737bd3d9cc910c082dd8dbd6c36ceb95d6/SKILL.md) names separate gates for assumptions, image generation, candidate selection, final-logo approval and VI/manual production. Generic praise or “continue” cannot manufacture approval. Once selected, the candidate image and its recorded invariants become the logo source of truth; later image editing may clean export quality or create lockups but may not silently redesign the mark.

```text
rough idea -> complete brief -> route approval -> generated candidates
-> named candidate selection -> locked final image set
-> approved application plan -> 21-part HTML VI manual
```

The decisive authority is therefore a project-bound set of approved image files plus the HTML/CSS manual, not an inferred vector graph. The checked-in examples show the expected intermediate interview, direction, gate, final-image and manual artifacts. That image-final choice is a real technical limitation: it preserves the selected visual source but does not provide native Bézier or constraint semantics for later logo editing.

The skill delegates rendering to the host agent and image generator; it does not claim a separate model or version service. No reliable maintainer-region evidence was found.
