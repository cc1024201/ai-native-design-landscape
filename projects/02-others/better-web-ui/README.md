# better-web-ui

> Research status: **Source-level** · Lifecycle: **active** · Last reviewed: **2026-08-12**

better-web-ui is a coordinated frontend skill library rather than a starter template. Setup learns the existing stack; focused skills can add a surface, extract a pattern, critique or audit it and refine typography, hierarchy, motion, accessibility and edge states without replacing the host system indiscriminately.

## Narrow skills share one project context

The package's architecture is progressive: `frontend-design` routes the task, `add-ui` mutates source, and `critique`/`audit` generate evidence for another pass. Existing source, component and token choices take precedence over library defaults.

The product boundary is the maintained package and compatibility wrappers. Its many small skills are operations within that product, not separate teams or canvases.
