# UserTesting

> Research status: **Architecture-level** · Last reviewed: **2026-08-12**

This record counts the canonical UserTesting product rather than treating its Figma plugin as a second company or artifact authority. The plugin is a launch and review surface for the same human-research platform.

## AI scaffolds a human Think-Out-Loud study

From Figma a designer can state a goal and ask AI to generate tasks and questions. The study launches to a reusable audience and returns participant feedback without requiring the designer to leave the design workspace for the basic loop.

| Layer | Authority |
|---|---|
| selected Figma prototype | design target |
| AI-produced tasks and questions | editable research plan scaffolding |
| audience and launched test | UserTesting platform study |
| recordings responses and feedback | human evidence |
| subsequent Figma change | still owned by the Figma file |

The plugin documentation explicitly says it does not replace the platform's advanced configuration. This prevents a misleading interpretation in which the embedded surface is assumed to expose every sampling targeting consent moderation or analysis capability.

## Identity and release boundary

The Figma integration was released in April 2026. It belongs to the established UserTesting platform and therefore resolves to one canonical dossier. UserTesting's public company material supports a United States team boundary; it does not reveal the internal plugin squad or stable employee count.

## Evidence ceiling

The plugin implementation task-generation prompt model routing prototype serializer study database and return channel are closed. Public documentation does not establish whether generated questions are versioned separately from the launched study or whether a changed Figma prototype invalidates an in-flight test. The human evidence remains more authoritative than an AI summary but still depends on audience construction and study quality.
