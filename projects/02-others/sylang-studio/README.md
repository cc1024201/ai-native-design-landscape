# Sylang Studio

> Research status: **Source-level** · Lifecycle: **active** · Last reviewed: **2026-08-12**

Sylang Studio is a systems-engineering specialization built on the Hermes Studio codebase. It is counted as the Sylang product only where the source activates an MBSE-specific work surface; the generic Hermes agent IDE is not treated as a second product.

## The brand seam is executable

The application shares a `studio-core`, while the Sylang build is selected through brand configuration such as `VITE_BRAND=sylang`. That seam changes the available product modules rather than merely replacing a logo. The Sylang surface adds model-based systems-engineering concerns to the common agent workspace.

## MBSE work objects

Coverage, traceability, and FMEA views make requirements, design elements, verification links, and failure analysis part of the working model. DSL and diagram editors provide two projections over those engineering objects. The important authority is the structured source and its cross-links, not a rendered diagram alone.

## Agent runtime inside engineering constraints

The inherited Studio runtime gives agents tools and workspace context, but Sylang's differentiator is the constraint domain around those tools. This dossier therefore classifies it as constraint-driven engineering rather than a general chat IDE. Execution quality and certification remain claims that require project-specific validation.
