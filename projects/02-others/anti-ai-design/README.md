# anti-ai-design

> Research status: **Source-level** · Lifecycle: **active** · Last reviewed: **2026-08-12**

anti-ai-design is an auto-routed UI authoring skill. It resolves platform and brand direction, offers two or three visual directions, then writes a CJX-ready multi-file HTML/CSS/JS bundle or adapts the output to a supported host stack.

## A frozen foundation separates system from screens

The bundle keeps `foundation.css` as the token authority, adds shared and screen-specific layers and records asset ownership. Later changes pass through a dedicated expansion path instead of regenerating unrelated platforms. A self-audit and aesthetic critique run before handoff.

Generated source is authoritative and the browser projection is derivative. The repository specifies this graph but does not prove visual quality for every combination of style and target stack.
