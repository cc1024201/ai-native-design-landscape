# Visual Authoring

> Research status: **Source-level** · Lifecycle: **active** · Last reviewed: **2026-08-12**

Visual Authoring is a portable agent skill rather than a design application. It defines design as turning source material into an intentional visual structure whose claims can be traced reviewed and released by a human.

## A gated method is the runtime

At commit [`16c2381`](https://github.com/vibeworkers/visual-authoring/tree/16c23819dd5136585fd43736b400eae7a1d6324a) [`SKILL.md`](https://github.com/vibeworkers/visual-authoring/blob/16c23819dd5136585fd43736b400eae7a1d6324a/SKILL.md) routes an agent from source inventory and reader intent through visual strategy artifact selection implementation review and human release. References encode domain judgment while scripts and fixtures enforce portable state and decision-preview contracts.

The skill can yield documents slides landing pages UI or learning material. It therefore does not own one universal artifact format. Authority stays with the selected artifact and its source files; the skill owns the process evidence and permission boundary.

```text
source -> reader decision -> visual strategy -> chosen artifact -> review -> human release
```

The checked-in provenance notes for absorbed methods and evaluation fixtures make method evolution inspectable. They do not prove that every downstream artifact is visually successful; rendered review remains necessary. Public first-party sources do not establish the organization region.
