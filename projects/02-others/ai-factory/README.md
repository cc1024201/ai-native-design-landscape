# AI Factory

> Research status: **Source-level** · Lifecycle: **active** · Last reviewed: **2026-08-12**

AI Factory organizes agent work around durable evidence bundles. Architecture diagrams, ADRs and plans are governed outputs of research and verification skills rather than incidental decorations in a transcript.

## Active Summary controls scope

At [`2a3b142e`](https://github.com/lee-to/ai-factory/tree/2a3b142ec0dfb1ce9db596584ae4ba5316c6fd9f), the workflow keeps a compact current-state summary so successive agents share goals, constraints and evidence. Research files retain source trails beyond that compressed coordination layer.

## Visuals belong to a planning bundle

Explore and plan skills can create C4, dependency and process diagrams alongside ADRs and task files. Verify and audit commands inspect the artifact set before implementation proceeds.

## Multi-agent packaging is portable

The installer transforms the same skills and subagent roles for several coding-agent hosts. Filesystem artifacts stay authoritative across those runtimes, which makes the design protocol more important than any single model provider.
