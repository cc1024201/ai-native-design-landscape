# Self-Review

> Research status: **Source-level** · Lifecycle: **active** · Last reviewed: **2026-08-12**

Self-Review defines Design as alignment among intent, the delivered artifact, reusable method and reported progress. It is a cross-domain agent audit rather than a visual-style critic: code, design, content, research and media can all be checked when they have an intended outcome and an observable deliverable.

## The audit is deliberately report-only

The skill first locks the current scope, then compares four pillars across six pairwise dimensions. It can run builds or artifact-specific commands, inspect current assumptions and distinguish missing work from work explicitly deferred to a later phase. Findings include evidence and recommendations, but the tool never silently edits the artifact it evaluates.

That separation makes the report a decision artifact and leaves source files as delivery authority. It also prevents a green build or a progress checkbox from being accepted as proof that the intended experience exists.
