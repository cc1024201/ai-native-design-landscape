# Codex Game Studio

> Research status: **Architecture-level** · Lifecycle: **active** · Last reviewed: **2026-08-12**

Codex Game Studio ports the operating model of Claude Code Game Studios into Codex-native skill discovery. Role skills cover direction, game and UI/UX design, visual art, engineering, QA and release; workflow skills move an idea through concept, GDD, production plan, implementation, UI flow, testing and delivery.

## Documents and handoffs carry the studio state

A studio orchestrator chooses a role or phase, while shared references define project briefs, GDDs, UI wireframes and release checks. The pack is deliberately not a game engine or runtime recreation: actual scene, code and asset authority stays in the consuming game repository.

Its Codex packaging and workflow adaptation make it independently usable, but the source lineage is explicit and materially limits the claim. This dossier records a derivative operating product, not a new invention of the underlying studio hierarchy.
