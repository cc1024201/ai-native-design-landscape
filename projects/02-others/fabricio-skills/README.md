# Fabricio Telles Skills

> Research status: **Source-level** · Lifecycle: **active** · Last reviewed: **2026-08-12**

This broad agent-skill collection enters the landscape through two operated Design surfaces rather than through its generic catalog identity. `design-md-validator` treats a DESIGN.md and token schema as testable system authority; `ultimate-design-system-master` routes brand identity, UI patterns, Figma layout, critique, accessibility, translation and presentation work into explicit deliverables.

## The collection is the distribution boundary

The visual skills share one maintained installation and attribution surface, so they are counted once rather than as a product per folder. Their artifacts differ—validated Design Markdown, tokens, brand/system specifications, implementation and review reports—but the repository is the versioned source that routes and updates them.

This is not evidence that every skill in the collection is a Design product. The inclusion rests on the independently usable visual authoring and governance workflows above.
