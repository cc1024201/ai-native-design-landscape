# Engineering Design Agent Skills

> Research status: **Source-level** · Lifecycle: **active** · Last reviewed: **2026-08-12**

This Codex plugin connects prose, images and drawings to a verified specification, build123d mechanical model, SKiDL/KiCad circuit and PCB-enclosure integration report.

## Source definitions precede neutral exchange

Mechanical Python is the parameterized authority; STEP is re-imported and checked as neutral exchange; STL, 3MF, DXF, SVG and PNG are derivative. Circuit Python produces topology, BOM/ERC, optional simulation and KiCad schematic output. An integration checker then evaluates coordinate frames, openings, envelopes and clearances across PCB and enclosure artifacts.

Rendered STEP and snapshot review return visual concerns to source expectations or measurements. These checks establish geometry and interface evidence but do not automatically prove strength, tolerances, certification or manufacturability.
