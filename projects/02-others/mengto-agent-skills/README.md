# Meng To Agent Skills

> Research status: **Source-level** · Lifecycle: **active** · Last reviewed: **2026-08-12**

Meng To's Skills repository is a large, author-owned operating library for visual product, brand, Web, game and media work. Its independent product boundary comes from a recurring workflow rather than the raw number of skill folders: observe a reference, translate it into reusable visual and interaction instructions, build, capture and audit the result.

## References become inspectable instructions, not copied pixels

A flagship route turns video into a structured superprompt, converts HTML behavior into interaction prompts, generates reference-inspired brand worlds and captures stitched pages for review. Originality and verification skills then test whether the result merely imitates a source or actually preserves the intended technique and experience.

The filesystem source and generated artifacts are authoritative; screenshots and recordings are evidence for iteration. The repository is counted once as one maintainer's coherent visual workflow suite, not once per skill and not as a generic third-party marketplace.
