# NanaDraw

> Research status: **Source-level** · Lifecycle: **active** · Last reviewed: **2026-08-12**

NanaDraw is a scientific-figure workflow, not a general diagram chatbot. It converts methods, sketches, papers, and visual references into editable publication-oriented figures.

## Three creation modes expose different authorities

Draft mode turns a method description into a plan and draw.io XML. Image generation produces visual material, while assembly mode combines generated and library assets. The embedded draw.io editor is where users can correct geometry and labels rather than accepting a flattened result.

## Research inputs remain traceable context

The upload path distinguishes images, PDF, Markdown, and text. PDFs are parsed through MinerU so selected passages can ground a figure; images can act as sketch references. More than 250 paper-style references and Bioicons influence visual vocabulary without becoming the user's source artifact.

## NanaSoul controls the canvas

The NanaSoul assistant can apply natural-language canvas operations. Projects persist locally, and exports include SVG, PowerPoint, and draw.io XML. A polished export still requires the author to verify scientific meaning, attribution, and journal constraints.
