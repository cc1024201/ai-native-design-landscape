# Premium Vector Icon Designer

> Research status: **Source-level** · Lifecycle: **active** · Last reviewed: **2026-08-12**

Premium Vector Icon Designer is a Codex-compatible skill for producing and repairing editable SVG icons and icon systems. It treats icon Design as geometry constrained by a grid, recognition at target size and maintainable SVG structure.

## Grid, construction and repair

The skill selects 24 px, 48/64 px or 1024 px construction grids according to the icon job. It requires connected strokes, controlled joins, purposeful hierarchy and a repair pass for malformed marks, accidental tangencies and glyph-like noise. SVG is the default authority, with no embedded bitmap and structure intended for later editing in Figma, Illustrator or code.

The ordinary loop supports new icons, set-level consistency, audit and revision. Optional grid assets make the construction frame inspectable; output rules constrain gradients, filters, masks and component export rather than leaving those choices to an opaque generation call.

## Evidence boundary

The public repository is a skill and reference system, not a renderer or hosted canvas. Its source proves the artifact contract and review gates, while aesthetic quality still depends on the executing agent and the user's review at actual display sizes.
