# AI Component Builder by StackedByAdit

> Research status: **Source-level** · Lifecycle: **active** · Last reviewed: **2026-08-12**

The product is a deliberately small browser component loop. Gemini writes React source; the user evaluates the same string as a component and can inspect it without a hidden project representation.

[`App.tsx`](https://github.com/StackedByAdit/AI_Component_Builder/blob/20ef38dfcf3341759a529d28cdabab97be720e42/src/App.tsx) holds the API key, prompt, generation request and cleaned model output. [`preview-panel.tsx`](https://github.com/StackedByAdit/AI_Component_Builder/blob/20ef38dfcf3341759a529d28cdabab97be720e42/src/preview-panel.tsx) composes a React/Babel/Tailwind `srcDoc` for visual execution and exposes the source in a neighboring tab.

No Firebase implementation is wired at this commit despite a package dependency, and there is no version or deployment state. Its independent count rests on its own runnable generation code rather than the generic repository title.
