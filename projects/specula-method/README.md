# Specula Method

> Research status: **Source-level** · Lifecycle: **active** · Last reviewed: **2026-08-12**

Specula Method defines AI-assisted design as strategic foresight branding. The work is not a logo generator: teams construct possible futures values refusal boundaries prototypes adaptive narratives and governance artifacts before activating a living brand system.

## The method produces governed state

At commit [`685e766`](https://github.com/oddtitoreal/specula-method/tree/685e766ddca9f3eeb76448e1254a4f5919595f5f) six phases move from scenario generation and brand archaeology through prototype stress tests narrative synthesis co-creation and ongoing monitoring. Generative models expand possibilities and mediate divergence but formal ethical gates and human review decide what advances.

The repository includes an [agent protocol](https://github.com/oddtitoreal/specula-method/blob/685e766ddca9f3eeb76448e1254a4f5919595f5f/agent/specula-method-agent.md) and JSON schemas for session state runtime steps and deliverables. The Registry of Refusals is as important as accepted candidates because it records what the brand deliberately will not become.

```text
futures -> identity model -> prototypes -> ethical gate -> narrative/governance -> monitoring
```

Private prompt libraries and client configurations are outside the repository so source proves the open method and artifact contracts rather than a complete hosted runtime. The maintainer's profile lists Pesaro Italy.
