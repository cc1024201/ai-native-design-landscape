# Computational Design Skills

> Research status: **Source-level** · Lifecycle: **active** · Last reviewed: **2026-08-12**

Computational Design Skills is an agent knowledge and calculation system for architecture engineering and fabrication. It defines design as a routed sequence of domain reasoning executable calculation and downstream CAD/BIM or fabrication materialization.

## Progressive disclosure separates method from arithmetic

At commit [`7a090c9`](https://github.com/Abhinavbwj/Claude-skills-for-Computational-Designers/tree/7a090c9ddc92e441b1419910673edbcfa7a962ed) a foundation skill selects among parametric modeling geometry facade structural environmental BIM fabrication and optimization skills. References provide domain constraints while seven Python calculators handle geometry solar structural mesh panel material and cost computations.

The distinction matters: prose guidance can shape the design but numerical results are produced by inspectable scripts such as the [panel optimizer](https://github.com/Abhinavbwj/Claude-skills-for-Computational-Designers/blob/7a090c9ddc92e441b1419910673edbcfa7a962ed/skills/cd-calculator/scripts/panel_optimizer.py). BIM templates and fabrication specifications are filesystem artifacts handed to the user's chosen authoring tool.

The package is not a unified visual editor and does not persist a native model itself. It is counted as a general-agent design toolkit whose value lies in routing and reproducible calculators. The maintainer's profile locates them in Oslo Norway.
