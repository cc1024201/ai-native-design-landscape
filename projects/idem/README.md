# Idem

> Research status: **Source-level** · Lifecycle: **active** · Last reviewed: **2026-08-12**

Idem defines design at company scale: one concept can expand into business strategy, brand assets, UML, a landing page, an application, documentation, and deployment. It is therefore classified as product delivery rather than merely a diagram editor.

## A managed project spans several generators

The monorepo contains an Angular orchestration surface, a Svelte Mermaid editor, a React/Express application generator, shared API services, and a deployment component. Firestore-backed project records bind outputs that would otherwise be isolated model responses.

## Visual design is one stage in a wider lifecycle

Brand and UML generation create reviewable artifacts; the Mermaid module allows direct source correction. Application generation and browser debugging then materialize a runnable project. Gemini and OpenAI integrations are means of production, while the managed company/project is the durable product object.

## The ambitious boundary should stay explicit

Source proves that these modules and handoffs exist. It does not prove that every generated company is commercially viable, that a visual concept exactly survives into code, or that one-click deployment creates production-ready operations. Each transition still needs user validation.
