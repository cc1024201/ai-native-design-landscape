# Claude Web Builder

> Research status: **Source-level** · Lifecycle: **active** · Last reviewed: **2026-08-12**

Claude Web Builder is a bilingual, beginner-oriented project kit that turns a short business interview into a custom landing page. It deliberately exposes ordinary checkpoints—brief questions, plan approval, local preview, feedback and optional deployment—instead of asking a non-technical user to operate thirteen underlying skills directly.

## The generated Next.js project is the durable result

After four rounds of intake, the agent builds source under `site/`, runs the local application and uses Playwright or a Chrome bridge for screenshots. The user reviews the actual page, asks for revisions, and only then may authorize a Vercel deployment. The live URL is a delivery projection; the user retains the source code.

Bundled frontend, accessibility, browser and deployment skills are dependencies of this one curated journey and are not recounted as Claude Web Builder products. Public evidence does not establish a separate hosted project model or version service.
