# Blender Agent Skill by Jithin Joseph

> Research status: **Source-level** · Lifecycle: **active** · Last reviewed: **2026-08-12**

This installable skill is a workflow companion for the upstream Blender MCP. It does not claim a new transport; it teaches an agent a reference-led modeling loop with parametric construction patterns, material/lighting helpers, multi-angle verification and recoverable milestones.

## Procedure adds correction discipline above a shared bridge

The [`SKILL.md`](https://github.com/jithinolickal/blender/blob/6bfca4973e7086696b08b108bfe6aae62ede33c0/skills/blender/SKILL.md) requires analyze → build simple → inspect → refine. [`workflow.md`](https://github.com/jithinolickal/blender/blob/6bfca4973e7086696b08b108bfe6aae62ede33c0/skills/blender/references/workflow.md) defines milestone and failure recovery, while [`viewport_helpers.py`](https://github.com/jithinolickal/blender/blob/6bfca4973e7086696b08b108bfe6aae62ede33c0/skills/blender/scripts/viewport_helpers.py) generates multi-angle evidence.

Blender's scene is authoritative and ahujasid's bridge supplies execution. The project is nevertheless an independent product boundary because it has its own installable plugin/skill release and reusable visual correction methodology.
