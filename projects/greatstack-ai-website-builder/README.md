# GreatStack AI Website Builder course project

> Research status: **Source-level** · Lifecycle: **active** · Last reviewed: **2026-08-12**

This record counts the AI Website Builder taught and distributed by GreatStack once. It does not count each learner repository as a new team or product. The [official project page](https://greatstack.dev/p/sitebuilder) names the product links the source assets preview Figma design and course video and reports more than two thousand builders.

## The course product owns a versioned HTML project

GreatStack's official source download is gated so implementation evidence was inspected through public learner copies. In a representative mirror [`schema.prisma`](https://github.com/rizwanullah-dev/AI-website-builder/blob/600a9e34a883fed12805187fd90b79bc78bd2ace/server/prisma/schema.prisma) separates projects conversations and versions and records the selected version and publication state. [`projectController.ts`](https://github.com/rizwanullah-dev/AI-website-builder/blob/600a9e34a883fed12805187fd90b79bc78bd2ace/server/controllers/projectController.ts) streams model generation and revision into complete HTML versions with rollback and public-page transitions.

The representative [`ProjectPreview.tsx`](https://github.com/rizwanullah-dev/AI-website-builder/blob/600a9e34a883fed12805187fd90b79bc78bd2ace/client/src/components/projects/ProjectPreview.tsx) renders the current document and supports element targeting. Source editing download and publication promote an adopted version rather than being implicit side effects of a prompt.
