# Webflow Project Template

> Research status: **Source-level** · Lifecycle: **active** · Last reviewed: **2026-08-12**

Webflow Project Template is a project-local operating system for agents that prepare a site in source files and then transfer it into Webflow. It combines an `AGENTS.md` contract, a static scaffold, style-guide extraction, component and page skills, class conventions and a durable page log.

## Source is prepared deliberately before host transfer

The repository treats the local HTML, CSS, scripts and design-system notes as the reviewable construction source. Webflow becomes the delivery authority only through an explicit transfer skill; the agent is not allowed to blur local experimentation with a successful host mutation. Figma and reference material can seed tokens and layout decisions, while page logs keep scope and completion visible.

This differs from Webflow's own MCP skills: it is an opinionated reusable project scaffold authored by an independent maintainer, not an official product surface or a second count of Webflow AI.
