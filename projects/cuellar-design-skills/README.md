# Carlos Cuellar Design Skills

> Research status: **Architecture-level** · Lifecycle: **active** · Last reviewed: **2026-08-12**

Carlos Cuellar's Design Skills is a method-and-template library for UX research, critique, accessibility, journey mapping, design systems, strategy, interaction design, design operations, writing and visual elevation. Each installable skill keeps a standalone contract and loads deeper references, templates and worked examples only when needed.

## Structured deliverables are the handoff mechanism

The collection specifies research plans, audit reports, journey and service maps, token architectures, component specs, handoff checklists and visual-elevation passes. Those records coordinate decisions and reviews, but the host agent and the consuming repository still own any actual implementation or rendered artifact.

Because no independent renderer, persistence service or mutation runtime is present, this dossier stops at architecture level. The repository is still relevant to the landscape because it explicitly defines Design as a family of evidence-bearing methods and handoff artifacts rather than generic aesthetic prompting.
