# Icon Design

> Research status: **Source-level** · Lifecycle: **active** · Last reviewed: **2026-08-12**

Kalebtec Icon Design makes candidate selection and lineage part of the artifact model. It starts with numbered icon territories, requires an explicit human choice before refinement and packages only a selected geometry as a production asset suite.

## IDs make exploration addressable

Discovery normally creates twenty concepts across five territories. Matching PNG and self-contained HTML sheets are generated from `concepts.json`; reviewers can select IDs in order and copy a precise continuation request. Refinement keeps parents and controls visible, never recycles IDs and archives rejected rounds.

Finalization begins only after a numbered choice. The selected SVG is checked at favicon sizes and across backgrounds, then rendered into canonical `currentColor`, black and white SVGs plus PNG, ICO, touch icon, app icon, social avatar and a reproducible zip.

The JSON/SVG working graph is authoritative. Review sheets are candidate projections; the zip is a derived delivery. A browser brief builder can initialize intent locally without account or upload state.
