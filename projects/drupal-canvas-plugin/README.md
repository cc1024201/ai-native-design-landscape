# Drupal Canvas Plugin

> Research status: **Source-level** · Lifecycle: **active** · Last reviewed: **2026-08-12**

Drupal Canvas Plugin is a marketplace source of Canvas component-development and site-migration skills for AI coding harnesses, not a Drupal runtime module.

## Three plugins divide the work

The repository packages seven Canvas component skills and two agents, nine Drupal-to-Canvas migration skills and sixteen agents, and nine Acquia Source migration skills and fifteen agents. Each group has its own setup, reference material, and role boundaries.

## Migration is a phased artifact protocol

Specialists analyze the source, extract CSS, build and audit components, test in Storybook, upload, configure media and menus, compose content, and visually verify the result. Files and checklists carry state across agent turns; Drupal Canvas remains the destination authority.

## One source targets multiple harnesses

Marketplace manifests and generated harness files install the same skills into Claude Code, Copilot CLI, Codex, Cursor, or Gemini CLI. Drupal DevKit distributes them but does not absorb their product identity.
