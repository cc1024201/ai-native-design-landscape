## Scope

An AI product-design environment producing interactive UI and exposing design/code context through MCP.

## Technical direction

- Treats design generation as an iterative product-design workflow rather than a static image generator.
- Connects designs to coding-agent workflows through MCP.
- Supports both design-to-code and code-to-design style workflows.
- Uses design-system context to keep generated UI coherent.

## Public technical choices

- Surface: browser-based UI design/generation workspace.
- Artifact: interactive UI/design with code output.
- Integration: MCP server.
- Context: design-system and product references.
