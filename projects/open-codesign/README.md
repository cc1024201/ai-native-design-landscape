## Scope

A local-first open-source AI design application covering prompt-to-prototype and other visual artifacts with comments, adjustments and versions.

## Technical direction

- Recreates a full AI-design product experience rather than only a narrow visual overlay.
- Supports multiple model providers and local-first workflows.
- Treats generated artifacts as iteratively editable objects.
- Includes design feedback/versioning mechanisms in the application itself.

## Public technical choices

- Surface: chat + visual artifact/canvas.
- Model layer: multi-provider.
- Interaction: comments, AI-driven adjustments and version history.
- Implementation: public repository.
