# Effective HTML

> Research status: **Source-level** · Lifecycle: **active** · Last reviewed: **2026-08-12**

Effective HTML is a cohesive set of six agent skills for turning design intent into self-contained browser artifacts: general HTML, creative direction, wireframes, prototypes, plans and diagrams. Each specialist owns a fidelity or relationship problem rather than applying one house style to every output.

## HTML source stays editable; the browser supplies evidence

The HTML file is the artifact authority. Responsive and accessible rendering, realistic states, keyboard behavior and browser inspection are projections used to test it. Wireframes remain deliberately unfinished so structure can be judged; prototypes implement one credible flow; plans preserve source commitments; diagrams choose a model appropriate to the relationship being explained.

The repository recommends Plannotator for rendered annotation and `tot.page` for sharing, but neither is embedded identity. Plannotator enters this census as its own review product; `tot.page` is excluded as publishing infrastructure without a Design-authoring or correction loop.
