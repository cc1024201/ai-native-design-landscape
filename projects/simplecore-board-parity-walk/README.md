# SimpleCORE Board Parity Walk

> Research status: **Architecture-level** · Lifecycle: **active** · Last reviewed: **2026-08-12**

Board Parity Walk is a verification product for projects that already have a SimpleCORE wireframe board. It is designed for long, multi-session audits in which a single agent would otherwise lose screen coverage, unresolved decisions and prior findings.

## The remaining-work list is the progress authority

Frames are grouped into clusters and compared with the running application. Fresh agents can inspect separate clusters, but shared facts are reduced into one handover file while narrative remains local. A parity list contains only what is left; a decision that cannot yet be settled is parked rather than silently accepted or allowed to stop the entire audit.

The board is the intended-structure reference, the running application is the observed projection, and handover/parity files preserve audit state. “Parity” is explicitly a floor: judgment lenses still ask whether the implemented experience is sensible rather than approving every literal match.
