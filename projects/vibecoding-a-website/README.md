# VibeCoding a Website

> Research status: **Source-level** · Lifecycle: **active** · Last reviewed: **2026-08-13**

VibeCoding a Website is not a graphical builder application. It is a coordinated skill and course product that makes a general agent carry one website from structured discovery through source generation visual and quality review Git publication Vercel deployment and later plain-language maintenance. Its Design authority is the filesystem and Git history rather than a proprietary canvas.

## A site brief is the handoff contract

[`site-interviewer/SKILL.md`](https://github.com/mrhinkle/VibeCoding-a-Website/blob/1ca085ae7fe4acc86fb0e6b2ce94b12a6a34a0d1/.claude/skills/site-interviewer/SKILL.md) converts a guided business and brand interview into `site-brief.json`. [`site-generator/SKILL.md`](https://github.com/mrhinkle/VibeCoding-a-Website/blob/1ca085ae7fe4acc86fb0e6b2ce94b12a6a34a0d1/.claude/skills/site-generator/SKILL.md) consumes that brief and writes either a multi-page HTML/CSS site or a Vite workspace.

The structured brief governs later generation but the generated website files become the durable implementation authority.

## The suite defines a lifecycle rather than one generation prompt

[`webmaster/SKILL.md`](https://github.com/mrhinkle/VibeCoding-a-Website/blob/1ca085ae7fe4acc86fb0e6b2ce94b12a6a34a0d1/.claude/skills/webmaster/SKILL.md) sequences planning generation UX and content audits deployment monitoring and iteration. [`site-updater/SKILL.md`](https://github.com/mrhinkle/VibeCoding-a-Website/blob/1ca085ae7fe4acc86fb0e6b2ce94b12a6a34a0d1/.claude/skills/site-updater/SKILL.md) locates source for a requested change tests it commits and pushes it so the hosted site is rebuilt. [`deploy-to-vercel/SKILL.md`](https://github.com/mrhinkle/VibeCoding-a-Website/blob/1ca085ae7fe4acc86fb0e6b2ce94b12a6a34a0d1/.claude/skills/deploy-to-vercel/SKILL.md) makes GitHub and Vercel the explicit promotion path.

This makes Design a governed delivery process performed by a general agent with visual evidence rather than a native design graph.

## What source evidence cannot prove

The repository supplies executable agent instructions and templates but not its own agent runtime. Claude Code Manus GitHub and Vercel perform the actions described by the skills. The dossier therefore establishes the interface and intended ordinary-user loop without claiming that every external step was executed during review.
