# Drup-AID

> Research status: **Source-level** · Lifecycle: **active** · Last reviewed: **2026-08-12**

Drup-AID is an early Drupal distribution that assembles Drupal AI, AI Agents, and Canvas into a governed content and site-building cockpit.

## A master agent delegates bounded roles

The distribution configures an orchestrator plus focused agents for analysis, content, SEO, and web editing. Most roles inspect and prescribe; the Content Writer and Web Editor are explicit mutation exceptions rather than evidence that every agent can write anything.

## Content changes use Drupal's revision system

Chat-controlled node and page edits pass through Drupal entities and permissions. Generated content remains draft unless publication is explicitly requested, and revisions preserve the normal CMS correction path.

## Canvas remains the visual authority

Drup-AID packages an operating experience around the official host instead of introducing another page model. Its distinct product definition is the agent team, cockpit, and permission policy applied to Drupal's existing artifact system.
