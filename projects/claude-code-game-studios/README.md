# Claude Code Game Studios

> Research status: **Source-level** · Lifecycle: **active** · Last reviewed: **2026-08-12**

Claude Code Game Studios turns one game repository into a role-separated studio with directors, department leads and specialists across game design, programming, art, audio, narrative, UX, QA, accessibility, localization and release. Skills and templates cover the route from an uncertain idea to design documents, production stories, tested builds and launch.

## Directors guard vision while hooks guard repository events

Project files—GDDs, UX specs, architecture decisions, sprint records, source, scenes and assets—carry the work between agents. Defined escalation paths stop specialists from silently overriding creative or technical direction. Hooks validate commits, pushes, asset changes and session events and retain an agent audit trail; quality gates review design, consistency, tests and release readiness.

Codex Game Studio explicitly ports this operating model, and gstack-game cites it as a domain source while rewriting its own review system. Those derivatives remain separate teams, but this upstream identity and influence are preserved.
