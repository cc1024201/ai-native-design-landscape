# Design Engineering Skills

> Research status: **Source-level** · Lifecycle: **active** · Last reviewed: **2026-08-12**

Farming Labs' Design Engineering Skills currently centers on one Codex skill for designing, building and refining frontend experiences, documentation, dashboards, studio tools, component libraries and design systems. It joins aesthetic direction to component APIs, interaction behavior, motion, icons, loading states and browser evidence.

## The consuming repository remains artifact authority

The skill writes ordinary application and design-system source rather than introducing a proprietary canvas. Browser-based visual QA and a design-audit script inspect the rendered result, after which the agent corrects the source. This makes it an agent operating layer over a code-native visual loop.

The repository is counted once at its present implemented scope. Its concise single-skill boundary is more accurate than projecting a future marketplace or treating every generated component as a product.
