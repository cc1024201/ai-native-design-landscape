# Claude Design Skill by jiji262

> Research status: **Source-level** · Lifecycle: **active** · Last reviewed: **2026-08-12**

This repository packages an independent, portable Design skill derived from the publicly observed Claude.ai Design workflow. It carries its own progressive instructions, design principles, style references, HTML canvas shell and prototype examples, so it can operate outside the hosted Claude surface.

## Candidate directions precede committed HTML

The agent gathers context, proposes distinct directions and lets the user choose before authoring the artifact. HTML source remains editable authority while a browser render, canvas shell and interaction checks expose layout and behavior for another pass. The repository's templates and demos make that contract independently executable.

Lineage matters: this is neither Anthropic's hosted Claude Design nor evidence about its private runtime. It is counted as an independent derivative product whose observable implementation and maintenance belong to jiji262.
