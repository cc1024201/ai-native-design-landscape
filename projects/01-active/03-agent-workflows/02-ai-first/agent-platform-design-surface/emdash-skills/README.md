# Emdash Skills

> Research status: **Source-level** · Lifecycle: **active** · Last reviewed: **2026-08-12**

Emdash Skills is a broad product-building operating system that routes a one-line SaaS or site request through brief, research, architecture, build, design system, motion, media, quality and deployment. Its Design definition is tightly coupled to delivery: brand and interface source must survive hard browser, accessibility and production gates.

## The repository and deployed runtime form two explicit authorities

Source modules define tokens, interaction rules, application slices and infrastructure. Parallel build and verify agents operate the consuming repository; Playwright screenshots at six breakpoints, vision review, Lighthouse, axe, SEO and console checks create release evidence. Only after those gates does the workflow deploy to Cloudflare and independently verify the live result.

The suite spans many non-Design categories, but its router and gate graph make it one coherent end-to-end product rather than a third-party catalog. Design-system, motion and media modules are internal stages and are not counted as separate teams.
