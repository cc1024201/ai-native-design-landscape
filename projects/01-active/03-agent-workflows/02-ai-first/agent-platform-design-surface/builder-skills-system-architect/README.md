# Builder Skills System Architect

> Research status: **Source-level** · Lifecycle: **active** · Last reviewed: **2026-08-12**

The System Architect skill in Builder Skills turns early visual or textual intent into an implementation-facing architecture package. It is a governed artifact protocol inside a broader skill collection.

## From whiteboard to buildable specification

At [`44692d45`](https://github.com/Tharun007-TK/builder-skills/tree/44692d45b3f3258a163701ca0841968188bcd19c), the skill asks the agent to clarify boundaries, components, data movement and operational constraints before producing the design. Mermaid C4 views are outputs of that structured reasoning.

## Design does not end at the diagram

The architecture package includes decisions and implementation guidance that feed the repository's backend, database and shipping skills. The diagram is coordination evidence inside a handoff chain rather than a standalone canvas.

## Counting boundary

Only the independently defined System Architect surface is represented here. Neighboring skills remain capabilities of the same collection unless they establish their own Design artifact authority.
