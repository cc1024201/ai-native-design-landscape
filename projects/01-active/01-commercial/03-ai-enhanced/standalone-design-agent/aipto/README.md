# AIPTO

> Research status: **Architecture-level** · Last reviewed: **2026-08-12**

AIPTO is a fashion and commerce visual-production workspace. Its central constraint is identity consistency across a set rather than generation of one attractive image.

## One node graph joins specialized tools

The canvas accepts model product and long-form visual references. An Agent can arrange nodes and choose among virtual try-on detail-page composition video and free-creation tools. Manual local repaint compositing angle changes and multi-model generation operate on selected outputs inside the same graph.

Three retained controls matter:

- a model identity lock carries the same person across shots;
- product-detail preservation keeps garment or merchandise attributes stable;
- sub-artboards and reusable technique templates preserve a workflow for another campaign or long commerce layout.

The ordinary loop therefore runs from references through a controllable graph to a coordinated family of assets: garment variants detail pages social video and high-resolution campaign media.

## Authority and delivery

The node-connected canvas is the continuing project artifact. Preview shares the same workflow with the professional workspace while export produces delivery images long pages or video. The public surface does not disclose node serialization version semantics or the exact model router so those remain unknown.

The first-party site exposes a running studio and paid canvas plans but no reliable legal location. Team region remains unknown rather than being inferred from language currency or domain.
