## The agent is advisory inside a long-form editor

Users import footage or generate scenes then arrange them on an unlimited-track timeline with frame-level precision. Voiceovers subtitles transitions character refinements and audio mixing remain timeline operations. The Movie Agent analyzes the current cut and recommends changes such as trimming a scene or emphasizing dialogue; the product explicitly lets the user accept or ignore those suggestions.

This matters for classifying authority. The agent does not replace the film project with a chat transcript. The accepted timeline is authoritative and a final render is its delivery projection. Public claims support projects from short clips to multi-hour films but do not reveal the storage graph collaboration model or whether generated-scene prompts remain attached to timeline instances.
