# Calcstack

> Research status: **Architecture-level** · Lifecycle: **active** · Last reviewed: **2026-08-12**

Calcstack presents a hosted suite of five AI-assisted editors: diagrams, circuits, agent workflows, resumes, and mind maps. Its public repository contains first-party product documentation and screenshots rather than the service implementation.

## Five editors define five different authorities

The diagram surface supports DSL-oriented generation and Excalidraw, React Flow, or Draw.io-style outputs. The circuit surface couples a schematic with simulation. Agent workflows are described as visual definitions that materialize into TypeScript. Resume and mind-map editors retain structured projects instead of only returning one-shot media.

## AI is positioned inside editable projects

Multi-model assistance generates or revises project material, while user editing and project persistence preserve control after the initial result. Collaboration and managed projects are product-level claims visible in the official surface. The decisive pattern is not one universal canvas but a shared hosted shell around several artifact-specific editors.

## Closed source limits the technical claim

The inspected repository does not expose the application runtime, persistence schema, provider adapters, or simulation engine. Consequently this dossier records demonstrated product contracts and documented architecture only. It does not infer that all five editors share a common data model or that generated workflows execute exactly as their screenshots imply.
