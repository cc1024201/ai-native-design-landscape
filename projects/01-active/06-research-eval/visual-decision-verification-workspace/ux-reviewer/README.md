# UX Reviewer

> Research status: **Source-level** · Lifecycle: **active** · Last reviewed: **2026-08-12**

UX Reviewer defines the application codebase as a traversable prototype. It discovers roles and routes, reconstructs each user's path screen by screen and produces a senior-design critique grounded in reachable behavior rather than visual impression alone.

## Its deliverable is a decision artifact

The skill maps workflows, counts interaction cost and records dead ends before writing a structured Markdown review into the project. Chat receives only a short summary; the durable report is the product output. It deliberately does not claim screenshot fidelity and does not silently rewrite the application.

That makes source files the experience authority and the review file the coordination boundary between designer and implementation agent.
