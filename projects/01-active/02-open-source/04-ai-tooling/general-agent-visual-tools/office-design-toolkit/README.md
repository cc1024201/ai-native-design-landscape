# Office Design Toolkit

> Research status: **Architecture-level** · Lifecycle: **active** · Last reviewed: **2026-08-12**

Office Design Toolkit defines a phase-ordered agent method for client-facing office artifacts: content first, information structure second, visual design third, and quality assurance before delivery. Its current public implementation is strongest for DOCX, with reusable typography, palette, table and brand rules.

## Phase order is the product's main control

The skill prevents style work from masking weak content or hierarchy. Design tokens and approved style packs are applied only after the information architecture is settled; a final checklist separates content, structure, visual and technical defects. The delivered office file remains authoritative and the checklist is review evidence.

README claims DOCX/XLSX/PPTX/PDF coverage, but the checked tree contains a DOCX design-system reference and lists richer PPTX/XLSX presets and packaging as roadmap work. This dossier therefore records the current architecture without upgrading future claims into implemented source evidence.
