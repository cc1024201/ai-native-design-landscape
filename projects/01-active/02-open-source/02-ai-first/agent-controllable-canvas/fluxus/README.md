# Fluxus

> Research status: **Source-level** · Lifecycle: **active** · Last reviewed: **2026-08-12**

Fluxus by LachPawel is a visual automation canvas where an AI assistant edits the same React Flow graph as the user through a constrained tool vocabulary.

## Tool calls are graph mutations

The Vercel AI SDK exposes operations such as adding, updating, deleting, and connecting nodes. Model output must select these operations and their structured arguments rather than returning an ungrounded prose workflow. The node registry bounds what can be instantiated.

## Templates and voice are alternate entry points

Templates provide known graph starting points, while voice input feeds the same assistant path as typed intent. Once materialized, every result is still a visible node or edge that can be moved and changed directly. The interface therefore keeps generated structure negotiable.

## Durable ownership is the weak edge

The inspected source demonstrates canvas mutation and in-session interaction, but not a substantial server-side project/version subsystem. Fluxus is counted for its real agent-to-canvas control path; claims about collaborative history, deployment execution, or cross-device recovery would require evidence beyond this revision.
