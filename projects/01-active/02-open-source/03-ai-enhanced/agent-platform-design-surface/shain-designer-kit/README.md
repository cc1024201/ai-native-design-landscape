# Shain Designer Kit

> Research status: **Source-level** · Lifecycle: **active** · Last reviewed: **2026-08-12**

Shain Designer Kit is a project starter that turns Claude Code into a role-separated design-and-development team. Business analysis, UX, UI, design review, accessibility, development, copy and testing advance through a declared pipeline instead of being collapsed into one unreviewed generation pass.

## Project memory survives skill and kit updates

`docs/todo.md` tracks work and `docs/lessons.md` records corrections for later sessions. The kit installs pinned upstream design skills, but keeps a source manifest and does not present those dependencies as its own implementations. Its updater backs up kit-owned files and preserves project work, memory, credentials and settings.

Generated application source is artifact authority; Figma and browser MCPs provide input and visual evidence. The separately published Shain Design System Skill enters the census as an independent companion because it has its own release and token-system contract.
