# Flock

> Research status: **Source-level** · Lifecycle: **active** · Last reviewed: **2026-08-12**

Flock is a desktop visual harness for designing and observing multi-agent work across model providers and isolated computer sandboxes.

## The graph coordinates agents and humans

React Flow nodes represent agents, prompts, tools, branching, aggregation, and human intervention. Saved versions and execution history let a user compare the authored structure with what actually ran rather than treating the most recent chat transcript as the workflow.

## Sandboxes make visual work observable

Agent tasks can execute in E2B or Daytona environments with a browser, VNC stream, files, and processes. Breakpoints and takeover allow a person to pause an agent and manipulate the same remote desktop when visual judgment or credentials are required.

## A workflow can become a service

Schedules and MCP exposure turn a saved design into an invocable capability. The sandbox, provider credentials, and external side effects remain separate resources, while the graph and its version history define the orchestrator-owned artifact.
