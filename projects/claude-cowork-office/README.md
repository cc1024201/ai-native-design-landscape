# Claude Cowork for Office

> Research status: **Source-level** · Lifecycle: **active** · Last reviewed: **2026-08-12**

Claude Cowork for Office defines design as the assembly of professional, illustrated office deliverables inside a local agent workspace. Diagrams are embedded evidence within documents, presentations, and research outputs—not the sole product.

## A plan-driven local agent

The application runs a multi-turn ReAct loop that can plan, call more than twenty built-in tools, use skills and MCP integrations, and modify files in a workspace. Anthropic- and OpenAI-compatible endpoints allow hosted or private models; GUI, CLI, and embedded modes expose the same underlying agent system.

## Rich documents are compound artifacts

The tool surface can produce Mermaid, SVG, generated images, Word, PDF, LaTeX, and PowerPoint material and then preview or edit outputs in the GUI. A report is therefore a bundle of source files, citations, visuals, and compiled delivery formats. The filesystem remains the recoverable authority behind a rendered PDF or slide deck.

## Autonomy ends at the user's environment

OS and MCP tools let the agent change more than a document, so plan visibility and output inspection are essential. Source proves the orchestration and editors; it does not prove factual accuracy, citation quality, or safe execution for every supported model and external tool.
