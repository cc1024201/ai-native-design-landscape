# PradaSlides

> Research status: **Architecture-level** · Lifecycle: **active** · Last reviewed: **2026-08-12**

PradaSlides defines presentation work as capability-aware routing. A short prompt or source pack becomes an internal brief, evidence-aware narrative and visual contract; the delivery route can be editable PPTX, native HTML, PDF or another requested format without asking ordinary users to manage the planning files.

## One intent, several artifact authorities

When format is unspecified the skill recommends editable PPTX as source of truth and an HTML presentation console rendered from that deck. For native HTML work, HTML becomes the source instead. This distinction avoids pretending that every output format shares one editable graph.

Media receives explicit roles and crop decisions. Visual QA covers contrast, typography, frame choice, crop integrity, topology rhythm and stage fit. The public benchmark demonstrates the HTML route and its presenter console; it does not establish equivalent implementation depth for every optional runtime or generated-media provider.
